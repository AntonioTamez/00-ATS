# Certificaciones de IA reconocidas

> Nota: los proveedores renuevan y retiran exámenes con frecuencia. Confirmar vigencia en el sitio oficial antes de inscribirse.

## Cloud (las más valoradas por empresas)

| Proveedor | Certificación | Nivel |
|-----------|---------------|-------|
| AWS | AI Practitioner | Fundamentos |
| AWS | Machine Learning Engineer – Associate | Intermedio |
| AWS | Generative AI Developer – Professional | Avanzado (la más nueva) |
| Google Cloud | Generative AI Leader | Negocio / liderazgo |
| Google Cloud | Professional Machine Learning Engineer | Avanzado (de las más respetadas) |
| Microsoft Azure | AI Fundamentals (AI-900) | Fundamentos |
| Microsoft Azure | AI Engineer Associate (AI-102) | Intermedio |
| Microsoft Azure | Data Scientist Associate (DP-100) | Intermedio |

## Plataformas y hardware

- **NVIDIA**: Generative AI LLMs Associate (NCA-GENL) y certificaciones de nivel Professional.
- **Databricks**: Generative AI Engineer Associate; Machine Learning Associate / Professional.

## Gobernanza, riesgo y auditoría

Área en fuerte crecimiento por regulaciones como el EU AI Act.

- **IAPP AIGP**: AI Governance Professional.
- **ISACA AAIA**: Advanced in AI Audit.
- **ISO/IEC 42001**: Lead Implementer / Lead Auditor (PECB y otros organismos).

## Aclaraciones

- Los "certificados" de Coursera, DeepLearning.AI o IBM son cursos: útiles para aprender, pero no equivalen a un examen supervisado de AWS, Google o Microsoft.
- La TensorFlow Developer Certificate fue discontinuada en 2024.

## Recomendación (perfil de arquitectura de software)

1. Elegir la certificación del cloud que se usa en el trabajo:
   - AWS Generative AI Developer – Professional
   - Google Cloud Professional Machine Learning Engineer
   - Azure AI Engineer Associate (AI-102)
2. Si interesa el lado de compliance, complementar con **IAPP AIGP**.
