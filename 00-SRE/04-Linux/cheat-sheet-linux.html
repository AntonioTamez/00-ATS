Referencia práctica · Bash / GNU Linux

Linux cheat sheet

Comandos esenciales agrupados por tarea, con ejemplos listos para adaptar y recordatorios para trabajar con seguridad.

Cómo leer los ejemplos

Sustituye archivo, ruta/, usuario y servicio por valores reales. # introduce comentarios; ~ es tu directorio personal. Los ejemplos asumen Bash y herramientas GNU; algunas opciones cambian en macOS o BusyBox.

Antes de ejecutar

Revisa la ruta con pwd y ls. Prueba búsquedas antes de añadir -delete. Evita pegar comandos con sudo sin entenderlos; los cambios y borrados pueden ser irreversibles.

01 /

Navegación y ayuda

pwd
Muestra la ruta actual.
ls -lah
Lista archivos, incluidos ocultos, con tamaños legibles.
cd ruta/ · cd .. · cd -
Entra, sube un nivel o vuelve al directorio anterior.
tree -L 2
Árbol de directorios a dos niveles; puede requerir instalación.
man comando
Abre el manual; sal con q.
comando --help
Consulta las opciones resumidas.
type comando · command -v comando
Identifica si es alias, función o ejecutable; localiza el comando.
02 /

Archivos y directorios

mkdir -p ruta/subdir
Crea directorios intermedios si faltan.
touch archivo.txt
Crea un archivo vacío o actualiza su fecha.
cp -i origen destino
Copia y pide confirmación si sobrescribe.
cp -a carpeta/ copia/
Copia un árbol preservando permisos y marcas de tiempo.
mv -i origen destino
Mueve o renombra; pregunta antes de sobrescribir.
ln -s /ruta/real enlace
Crea un enlace simbólico.
stat archivo · file archivo
Consulta metadatos o detecta el tipo de archivo.
rm -i archivo CUIDADO
Borra con confirmación. No hay papelera estándar.
rmdir carpeta_vacia
Elimina únicamente un directorio vacío.
03 /

Leer y transformar texto

less archivo.log
Lee por páginas; busca con /texto y sal con q.
head -n 20 archivo · tail -n 20 archivo
Muestra las primeras o últimas 20 líneas.
tail -f archivo.log
Sigue nuevas líneas; detén con Ctrl+C.
wc -l archivo
Cuenta líneas.
sort archivo | uniq -c
Ordena y cuenta líneas repetidas contiguas.
cut -d, -f1 datos.csv
Extrae la primera columna separada por comas; no interpreta CSV con comillas.
sed -n '10,20p' archivo
Muestra de la línea 10 a la 20.
awk '{print $1}' archivo
Imprime el primer campo separado por espacios.
diff -u antes despues
Compara dos archivos en formato unificado.
04 /

Buscar y filtrar

grep -n 'texto' archivo
Busca coincidencias y muestra números de línea.
grep -Rni 'texto' ruta/
Busca recursivamente sin distinguir mayúsculas.
grep -E 'error|warn' archivo
Busca con expresión regular extendida.
find ruta/ -type f -name '*.log'
Encuentra archivos por nombre; las comillas evitan expansión previa.
find ruta/ -type f -mtime -7
Archivos modificados en los últimos siete días.
find ruta/ -type f -size +100M
Archivos mayores de 100 MiB.
find ruta/ -type f -name '*.tmp' -print
Previsualiza resultados antes de cualquier borrado.
rg -n 'texto' ruta/
Búsqueda rápida si ripgrep está instalado; respeta exclusiones habituales.
05 /

Permisos y usuarios

En rwx: lectura = 4, escritura = 2, ejecución = 1; orden: propietario, grupo, otros.

ls -l archivo
Muestra propietario, grupo y permisos.
chmod u+x script.sh
Da ejecución al propietario.
chmod 644 archivo
Lectura general y escritura solo del propietario.
chmod 755 script.sh
Ejecución general; escritura solo del propietario.
chown usuario:grupo archivo
Cambia propietario y grupo; suele requerir sudo.
id · whoami
Muestra identidad, grupos o usuario actual.
sudo -l
Lista las operaciones permitidas con sudo.
06 /

Procesos y servicios

ps aux
Lista procesos y consumo de recursos.
top
Monitor interactivo; sal con q.
pgrep -af nombre
Busca PID y línea de comando.
kill -TERM PID
Solicita una parada ordenada.
jobs · fg %1 · bg %1
Consulta trabajos y pásalos a primer o segundo plano.
systemctl status servicio
Estado de un servicio en sistemas con systemd.
sudo systemctl restart servicio CUIDADO
Reinicia el servicio; puede interrumpir conexiones.
journalctl -u servicio -n 50 --no-pager
Últimas 50 entradas del diario del servicio.
07 /

Sistema, disco y memoria

uname -a · cat /etc/os-release
Kernel y distribución.
uptime
Tiempo activo y carga media.
free -h
Uso de memoria en unidades legibles.
df -h · df -i
Espacio libre o inodos por sistema de archivos.
du -sh ruta/
Tamaño total de una carpeta.
lsblk -f
Discos, particiones y sistemas de archivos.
date -Is · timedatectl
Fecha ISO y configuración de hora si usa systemd.
dmesg -T | tail -n 30
Mensajes recientes del kernel; puede requerir permisos.
08 /

Red y diagnóstico

ip -br addr · ip route
Interfaces e IP; tabla de rutas.
ping -c 4 ejemplo.com
Prueba conectividad ICMP; algunos destinos la bloquean.
getent hosts ejemplo.com
Resuelve un nombre con la configuración del sistema.
ss -tuln
Puertos TCP/UDP en escucha, sin resolver nombres.
curl -I https://ejemplo.com
Solicita cabeceras HTTP.
curl -fL -o archivo URL
Descarga a un archivo y falla ante errores HTTP.
traceroute ejemplo.com
Rastrea saltos; puede requerir instalación.
09 /

SSH y transferencia

ssh usuario@servidor
Conecta por SSH; verifica la huella del host la primera vez.
ssh -i ~/.ssh/clave usuario@servidor
Conecta con una clave privada concreta.
scp archivo usuario@servidor:/ruta/
Copia un archivo al servidor.
rsync -avh --progress origen/ destino/
Sincroniza el contenido de origen/ hacia destino/.
rsync -avhn --delete origen/ destino/ CUIDADO
Simula una sincronización con borrados; revisa antes de quitar -n.
10 /

Gestores de paquetes

Usa el gestor de tu distribución. Las instalaciones y actualizaciones suelen requerir sudo.

apt search nombre
Busca paquetes en Debian / Ubuntu.
sudo apt update
Actualiza el índice de paquetes.
sudo apt install paquete
Instala un paquete en Debian / Ubuntu.
dnf search nombre
Busca paquetes en Fedora / RHEL recientes.
sudo dnf install paquete
Instala con DNF.
pacman -Ss nombre
Busca paquetes en Arch Linux.
sudo pacman -Syu
Sincroniza repositorios y actualiza Arch.
11 /

Archivos comprimidos

tar -czf copia.tar.gz carpeta/
Crea un archivo tar comprimido con gzip.
tar -tzf copia.tar.gz
Lista su contenido antes de extraer.
tar -xzf copia.tar.gz -C destino/
Extrae en un directorio existente; revisa antes rutas del archivo.
gzip -k archivo
Comprime y conserva el original.
unzip -l archivo.zip
Lista un ZIP sin extraer; puede requerir instalación.
unzip archivo.zip -d destino/
Extrae un ZIP en la carpeta indicada.
12 /

Shell y composición

fecha=$(date +%F)
Guarda la fecha de un comando en una variable de Bash.
comando1 | comando2
Envía la salida estándar del primero al segundo.
comando > salida.txt · comando >> salida.txt
Sobrescribe o añade a un archivo.
comando 2> error.log
Redirige solo los errores.
comando && siguiente
Ejecuta el siguiente solo si el primero termina bien.
echo "$VARIABLE" · export VARIABLE=valor
Lee o exporta una variable; cita expansiones en rutas y texto.
printf '%s\n' "$VARIABLE"
Imprime texto de forma predecible.
Ctrl+C · Ctrl+L · Ctrl+R
Interrumpe, limpia pantalla o busca en el historial.

No hay comandos que coincidan. Prueba con otra palabra.

Regla útil: primero inspecciona, después modifica. Para operaciones sensibles, consulta man comando, valida la ruta y prueba con opciones como -n cuando estén disponibles. Para crear el PDF, usa «Imprimir / guardar PDF» y selecciona A4 con gráficos de fondo activados.
