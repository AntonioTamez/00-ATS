# Clase 11.2: jq Avanzado - Filtros y Transformaciones

## 🎯 Objetivo
Aprender a filtrar, transformar y manipular datos JSON con jq.

## ⏱️ Duración: 20-25 minutos

---

## 📝 Guión de la Clase

### Intro (1 min)
"Ahora que sabemos extraer datos, vamos a filtrar y transformar. Esto es lo que realmente necesitas cuando trabajas con respuestas de AWS CLI o Kubernetes."

### Setup: Crear datos de práctica (2 min)

```bash
cat << 'EOF' > ./instances.json
{
  "Instances": [
    {"InstanceId": "i-001", "State": "running", "Type": "t2.micro", "Tags": [{"Key": "Name", "Value": "web-prod"}]},
    {"InstanceId": "i-002", "State": "stopped", "Type": "t2.small", "Tags": [{"Key": "Name", "Value": "web-dev"}]},
    {"InstanceId": "i-003", "State": "running", "Type": "t2.medium", "Tags": [{"Key": "Name", "Value": "db-prod"}]},
    {"InstanceId": "i-004", "State": "running", "Type": "t2.micro", "Tags": [{"Key": "Name", "Value": "cache-prod"}]},
    {"InstanceId": "i-005", "State": "terminated", "Type": "t2.large", "Tags": [{"Key": "Name", "Value": "old-server"}]}
  ]
}
EOF
```

### Demo 1: Filtrar con select() (5 min)

```bash
# Filtrar instancias running
jq '.Instances[] | select(.State == "running")' ./instances.json

# Solo IDs de instancias running
jq -r '.Instances[] | select(.State == "running") | .InstanceId' ./instances.json

# Múltiples condiciones (AND)
jq '.Instances[] | select(.State == "running" and .Type == "t2.micro")' ./instances.json

# Condiciones OR
jq '.Instances[] | select(.State == "running" or .State == "stopped")' ./instances.json

# Negación
jq '.Instances[] | select(.State != "terminated")' ./instances.json
```

### Demo 2: Transformar datos (4 min)

```bash
# Crear nuevo formato
jq '.Instances[] | {id: .InstanceId, estado: .State}' ./instances.json

# Convertir a array
jq '[.Instances[] | {id: .InstanceId, estado: .State}]' ./instances.json

# String interpolation
jq -r '.Instances[] | "\(.InstanceId) - \(.State) - \(.Type)"' ./instances.json
```

### Demo 3: Operaciones con arrays (4 min)

```bash
# Contar con condición
jq '[.Instances[] | select(.State == "running")] | length' ./instances.json

# Ordenar
jq '.Instances | sort_by(.Type)' ./instances.json

# Valores únicos
jq '[.Instances[].Type] | unique' ./instances.json

# Map
jq '.Instances | map(.InstanceId)' ./instances.json
```

### Demo 4: Formato de salida (3 min)

```bash
# Formato TSV
jq -r '.Instances[] | [.InstanceId, .State, .Type] | @tsv' ./instances.json

# Formato CSV
jq -r '.Instances[] | [.InstanceId, .State, .Type] | @csv' ./instances.json
```

### Cierre (2 min)
"select() es tu filtro principal. Con esto puedes procesar cualquier respuesta de AWS, Docker o Kubernetes."

## 💻 Comandos de la Clase

```bash
jq '.[] | select(.campo == "valor")'           # Filtrar
jq '.[] | select(.a and .b)'                   # AND
jq '.[] | select(.a or .b)'                    # OR
jq '[.[] | {nuevo: .viejo}]'                   # Transformar
jq '. | sort_by(.campo)'                       # Ordenar
jq -r '.[] | [.a, .b] | @csv'                  # CSV
```
