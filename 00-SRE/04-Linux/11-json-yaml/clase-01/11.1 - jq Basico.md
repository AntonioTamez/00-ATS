# Clase 11.1: jq Básico - Procesando JSON

## 🎯 Objetivo
Aprender a leer, filtrar y extraer datos de JSON con jq.

## ⏱️ Duración: 20-25 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"En el mundo de APIs, Cloud y DevOps, JSON está en todas partes. AWS CLI, Docker, Kubernetes, APIs REST... todo devuelve JSON. jq te permite procesar esa información desde la terminal."

### Setup: Verificar instalación (1 min)

```bash
# Verificar si jq está instalado
jq --version

# Si no está instalado (en WSL/Ubuntu):
sudo apt update && sudo apt install -y jq
```

### Demo 1: Formatear JSON (pretty print) (3 min)

```bash
# JSON sin formato (difícil de leer)
echo '{"name":"jean","role":"devops","skills":["linux","docker","k8s"]}'

# Con jq (formateado)
echo '{"name":"jean","role":"devops","skills":["linux","docker","k8s"]}' | jq .

# Desde archivo
cat << 'EOF' > ./user.json
{"name":"jean","role":"devops","skills":["linux","docker","k8s"],"active":true}
EOF

cat ./user.json | jq .
jq . ./user.json
```

### Demo 2: Extraer campos (5 min)

```bash
# Extraer campo simple
echo '{"name":"jean","role":"devops"}' | jq '.name'
# Output: "jean" (con comillas)

# Sin comillas (-r = raw)
echo '{"name":"jean","role":"devops"}' | jq -r '.name'
# Output: jean

# Múltiples campos
echo '{"name":"jean","role":"devops","age":30}' | jq '.name, .role'

# Crear nuevo objeto con campos seleccionados
echo '{"name":"jean","role":"devops","age":30,"city":"Lima"}' | jq '{nombre: .name, trabajo: .role}'
```

### Demo 3: JSON anidado (4 min)

```bash
# Crear JSON anidado
cat << 'EOF' > ./server.json
{
  "server": {
    "name": "web-prod-01",
    "ip": "192.168.1.100",
    "config": {
      "cpu": 4,
      "memory": "8GB",
      "disk": "100GB"
    }
  },
  "status": "running"
}
EOF

# Acceder a campos anidados
jq '.server.name' ./server.json
jq '.server.config.cpu' ./server.json
jq -r '.server.ip' ./server.json
```

### Demo 4: Arrays (5 min)

```bash
# Crear JSON con array
cat << 'EOF' > ./servers.json
{
  "servers": [
    {"name": "web-01", "ip": "192.168.1.10", "status": "running"},
    {"name": "web-02", "ip": "192.168.1.11", "status": "stopped"},
    {"name": "db-01", "ip": "192.168.1.20", "status": "running"}
  ]
}
EOF

# Acceder a elemento por índice
jq '.servers[0]' ./servers.json
jq '.servers[0].name' ./servers.json

# Todos los elementos
jq '.servers[]' ./servers.json

# Campo específico de todos los elementos
jq -r '.servers[].name' ./servers.json
jq -r '.servers[].ip' ./servers.json

# Contar elementos
jq '.servers | length' ./servers.json
```

### Demo 5: Caso práctico - API Response (3 min)

```bash
# Simular respuesta de API de GitHub
curl -s https://api.github.com/users/torvalds | jq .

# Extraer campos específicos
curl -s https://api.github.com/users/torvalds | jq '{login, name, public_repos, followers}'

# Solo valores
curl -s https://api.github.com/users/torvalds | jq -r '.name'
```

### Cierre (2 min)
"jq básico te permite leer cualquier respuesta JSON. En la siguiente clase veremos filtros avanzados para seleccionar datos específicos."

---

## 💻 Comandos de la Clase

```bash
jq .                            # Formatear JSON
jq '.campo'                     # Extraer campo
jq -r '.campo'                  # Extraer sin comillas
jq '.campo1, .campo2'           # Múltiples campos
jq '.padre.hijo'                # Campo anidado
jq '.array[0]'                  # Primer elemento de array
jq '.array[]'                   # Todos los elementos
jq '.array[].campo'             # Campo de cada elemento
jq '. | length'                 # Contar elementos
jq '{nuevo: .viejo}'            # Crear nuevo objeto
```
