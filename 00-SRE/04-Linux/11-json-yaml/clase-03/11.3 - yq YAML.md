# Clase 11.3: yq - Procesando YAML

## 🎯 Objetivo
Aprender a leer y modificar archivos YAML con yq, esencial para Kubernetes y configuraciones.

## ⏱️ Duración: 15-20 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"YAML es el formato estándar en Kubernetes, Docker Compose, Ansible, GitHub Actions... Si trabajas en DevOps, trabajas con YAML. yq es como jq pero para YAML."

### Setup: Instalar yq (2 min)

```bash
# Verificar si está instalado
yq --version

# Instalar yq (versión de Mike Farah - la más usada)
sudo wget -qO /usr/local/bin/yq https://github.com/mikefarah/yq/releases/latest/download/yq_linux_amd64
sudo chmod +x /usr/local/bin/yq

# Verificar instalación
yq --version
```

### Setup: Crear archivos de práctica (2 min)

```bash
# Deployment de Kubernetes
cat << 'EOF' > ./deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: web-app
  labels:
    app: web
    environment: production
spec:
  replicas: 3
  selector:
    matchLabels:
      app: web
  template:
    spec:
      containers:
        - name: nginx
          image: nginx:1.19
          ports:
            - containerPort: 80
          resources:
            limits:
              cpu: "500m"
              memory: "128Mi"
EOF
```

### Demo 1: Leer valores (4 min)

```bash
# Ver todo formateado
yq . ./deployment.yaml

# Leer campo específico
yq '.metadata.name' ./deployment.yaml

# Leer campo anidado
yq '.spec.replicas' ./deployment.yaml

# Leer de array
yq '.spec.template.spec.containers[0].image' ./deployment.yaml

# Leer labels
yq '.metadata.labels' ./deployment.yaml
```

**Explicar**: "La sintaxis es casi idéntica a jq. Si sabes jq, sabes yq."

### Demo 2: Modificar valores (5 min)

```bash
# Crear copia para modificar
cp ./deployment.yaml ./deploy-test.yaml

# Modificar valor (sin -i solo muestra resultado)
yq '.spec.replicas = 5' ./deploy-test.yaml

# Modificar in-place
yq -i '.spec.replicas = 5' ./deploy-test.yaml
cat ./deploy-test.yaml | grep replicas

# Cambiar imagen
yq -i '.spec.template.spec.containers[0].image = "nginx:1.21"' ./deploy-test.yaml

# Agregar nuevo label
yq -i '.metadata.labels.version = "v2"' ./deploy-test.yaml

# Verificar cambios
yq '.metadata.labels' ./deploy-test.yaml
```

### Demo 3: Agregar y eliminar campos (3 min)

```bash
# Agregar nuevo campo
yq -i '.metadata.annotations.author = "jean"' ./deploy-test.yaml

# Eliminar campo
yq -i 'del(.metadata.labels.version)' ./deploy-test.yaml

# Agregar elemento a array
yq -i '.spec.template.spec.containers += [{"name": "sidecar", "image": "busybox"}]' ./deploy-test.yaml
```

### Demo 4: Conversiones (2 min)

```bash
# YAML a JSON
yq -o=json ./deployment.yaml

# JSON a YAML
echo '{"name": "test", "value": 123}' | yq -P

# Evaluar expresión
yq '.spec.replicas * 2' ./deployment.yaml
```

### Demo 5: Caso práctico - Script de deploy (3 min)

```bash
# Escenario: Actualizar imagen antes de deploy
IMAGE_TAG="v1.2.3"
yq -i ".spec.template.spec.containers[0].image = \"myapp:${IMAGE_TAG}\"" ./deploy-test.yaml

# Escenario: Escalar para producción
REPLICAS=10
yq -i ".spec.replicas = ${REPLICAS}" ./deploy-test.yaml

# Verificar
yq '.spec.replicas, .spec.template.spec.containers[0].image' ./deploy-test.yaml
```

### Cierre (2 min)
"yq te permite automatizar cambios en YAML sin romper la indentación. Muy útil para CI/CD pipelines donde necesitas modificar manifiestos de Kubernetes."

---

## 💻 Comandos de la Clase

```bash
# Leer
yq '.campo' archivo.yaml                    # Leer campo
yq '.padre.hijo' archivo.yaml               # Campo anidado
yq '.array[0]' archivo.yaml                 # Elemento de array

# Modificar
yq -i '.campo = "valor"' archivo.yaml       # Modificar in-place
yq -i '.campo = 123' archivo.yaml           # Valor numérico
yq -i 'del(.campo)' archivo.yaml            # Eliminar campo

# Agregar
yq -i '.nuevo = "valor"' archivo.yaml       # Nuevo campo
yq -i '.array += ["item"]' archivo.yaml     # Agregar a array

# Conversiones
yq -o=json archivo.yaml                     # YAML a JSON
cat json | yq -P                            # JSON a YAML
```
