# Clase 0.2: Solicitar Servidor Linux y Conexión SSH

## 🎯 Objetivo
Obtener acceso a un servidor Linux de práctica en la comunidad, conectarte por SSH desde Windows (PowerShell), Mac o Terminal, y cambiar tu contraseña temporal en el primer inicio de sesión.

## ⏱️ Duración: 10-12 minutos

---

## 📝 Parte 1: Solicitar tu Servidor Linux

En lugar de crear y configurar una máquina virtual de AWS desde cero (lo cual se ve a fondo en el **Curso de AWS**), para este curso puedes **pedir tu propio servidor Linux** para probar y practicar directamente en la comunidad.

1. Solicita tu servidor en la comunidad (del mismo modo que se piden las cuentas de AWS).
2. Se te entregarán **3 valores importantes**:
   - **Nombre de usuario**
   - **IP del servidor**
   - **Contraseña temporal**

Guarda estos datos, los usarás para conectarte.

---

## 🔌 Parte 2: Primer Conexión SSH y Cambio de Contraseña

### 1. Abrir PowerShell o Terminal
- **Windows:** Presiona `Win + X` y selecciona "Windows PowerShell" o "Terminal"
- **Mac/Linux:** Abre tu terminal habitual

### 2. Conectarte a tu Servidor
Usa el comando `ssh` seguido de tu usuario y la IP del servidor que te proporcionaron.

```bash
ssh tu_usuario@IP_DEL_SERVIDOR
```
*(Ejemplo: `ssh juan@198.51.100.25`)*

### 3. Aceptar la conexión y usar la contraseña temporal
- La primera vez que te conectes, la terminal te preguntará si confías en el servidor (`Are you sure you want to continue connecting (yes/no/[fingerprint])?`). Escribe `yes` y presiona Enter.
- Te pedirá la contraseña. Escribe la **contraseña temporal** que te dieron. (Nota: en Linux, mientras escribes tu contraseña no verás nada en pantalla, ni asteriscos. Es normal, solo escríbela y da Enter).

### 4. Cambiar la contraseña (Obligatorio)
Inmediatamente después de ingresar correctamente, el sistema te pedirá cambiarla por seguridad:
1. **(Current) UNIX password:** Escribe nuevamente la **contraseña temporal**.
2. **New password:** Escribe tu **nueva contraseña** (que solo tú vas a saber).
3. **Retype new password:** Escribe la **nueva contraseña otra vez** para confirmar.

Una vez que se cambie con éxito, la conexión se cerrará automáticamente en la terminal por seguridad.

---

## 🔄 Parte 3: Reloguearse al Servidor (Reconectar)

Ahora que ya tienes tu propia contraseña, vuelve a conectarte ejecutando el mismo comando:

```bash
ssh tu_usuario@IP_DEL_SERVIDOR
```

Esta vez, ingresa la **nueva contraseña** que acabas de configurar.

---

## ✅ ¡Conectado!

Cuando veas algo parecido a esto, ya estás dentro de tu servidor:
```bash
tu_usuario@servidor-practicas:~$
```

Para probar que todo funciona, ejecuta estos comandos:
```bash
# Verificar la información de Linux
uname -a

# Ver información del sistema operativo
cat /etc/os-release
```

---

## 🔌 Desconectarte

Para salir del servidor en cualquier momento, escribe:
```bash
exit
```
