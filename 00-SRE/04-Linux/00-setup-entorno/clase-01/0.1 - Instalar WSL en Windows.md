## 🎯 Objetivo
Instalar Windows Subsystem for Linux para practicar en tu PC.

## ⏱️ Duración: 5 minutos

## 📝 Instrucciones Rápidas

### Requisitos
- Windows 10 (versión 2004+) o Windows 11
- Permisos de administrador

### Instalación

1. **Abrir PowerShell como Administrador**
   - Click derecho en el menú inicio
   - Seleccionar "Windows PowerShell (Admin)" o "Terminal (Admin)"

2. **Ver distribuciones disponibles**
```powershell
wsl --list --online
```

Verás algo como esto:
```
NAME                            FRIENDLY NAME
Ubuntu                          Ubuntu
Ubuntu-24.04                    Ubuntu 24.04 LTS
Debian                          Debian GNU/Linux
kali-linux                      Kali Linux Rolling
AlmaLinux-9                     AlmaLinux OS 9
Fedora Linux-42                 Fedora Linux 42
... y más
```

3. **Instalar la distribución**

💡 **Recomendación:** Usa **Ubuntu** porque es lo que más usaremos en los cursos y es la más fácil de aprender.

```powershell
wsl --install -d Ubuntu-24.04
```

O si prefieres la versión por defecto:
```powershell
wsl --install
```

4. **Reiniciar tu PC** cuando te lo pida

5. **Configurar Ubuntu**
   - Después del reinicio, se abrirá Ubuntu automáticamente
   - Crea un usuario y contraseña (esta contraseña es solo para Linux)

6. **Verificar instalación**
```powershell
wsl --version
```

---

## 🔄 Comandos Útiles de WSL

```powershell
# Ver distribuciones instaladas
wsl --list --verbose

# Iniciar Ubuntu
wsl

# Actualizar WSL
wsl --update
```

---

## ⚠️ Nota Importante

WSL es perfecto para practicar los primeros módulos del curso. Sin embargo, para las clases de servicios (Nginx) y algunas funcionalidades avanzadas, necesitarás una VM real en AWS.
