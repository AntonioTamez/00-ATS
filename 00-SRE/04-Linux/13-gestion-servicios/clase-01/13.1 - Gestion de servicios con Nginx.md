# Clase 13.1: Gestión de Servicios (con Nginx)

## 🎯 Objetivo
Aprender a instalar, iniciar, detener y administrar servicios en Linux.

## ⏱️ Duración: 5-7 minutos

---

## ¿Qué es un Servicio?

Un servicio es un programa que corre en segundo plano. Ejemplos:
- Nginx (servidor web)
- MySQL (base de datos)
- SSH (conexiones remotas)

---

## Instalar Nginx

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install nginx -y

# Amazon Linux
sudo yum install nginx -y
# o
sudo dnf install nginx -y
```

---

## Ver Estado del Servicio

```bash
sudo systemctl status nginx
```

**Estados posibles:**
- `active (running)` - Funcionando ✅
- `inactive (dead)` - Detenido
- `failed` - Error

---

## Iniciar el Servicio

```bash
sudo systemctl start nginx
```

Verifica:
```bash
curl localhost
# Deberías ver HTML de nginx
```

---

## Detener el Servicio

```bash
sudo systemctl stop nginx
```

Verifica:
```bash
curl localhost
# Error: Connection refused
```

---

## Reiniciar el Servicio

```bash
sudo systemctl restart nginx
```

Útil después de cambiar configuración.

---

## Recargar Configuración (sin detener)

```bash
sudo systemctl reload nginx
```

Mejor que restart porque no hay interrupción.

---

## Habilitar al Inicio del Sistema

```bash
# El servicio inicia automáticamente al encender el servidor
sudo systemctl enable nginx

# Verificar
sudo systemctl is-enabled nginx
```

---

## Deshabilitar del Inicio

```bash
sudo systemctl disable nginx
```

---

## Comandos Combinados

```bash
# Habilitar e iniciar al mismo tiempo
sudo systemctl enable --now nginx

# Deshabilitar y detener
sudo systemctl disable --now nginx
```

---

## Ver Logs del Servicio

```bash
# Ver logs recientes
sudo journalctl -u nginx

# Ver logs en tiempo real
sudo journalctl -u nginx -f
```

---

## Otros Servicios Comunes

Estos comandos funcionan igual para cualquier servicio:

```bash
sudo systemctl status ssh
sudo systemctl status mysql
sudo systemctl status docker
```

---

## 📋 Resumen

```bash
sudo systemctl status servicio    # Ver estado
sudo systemctl start servicio     # Iniciar
sudo systemctl stop servicio      # Detener
sudo systemctl restart servicio   # Reiniciar
sudo systemctl reload servicio    # Recargar config
sudo systemctl enable servicio    # Iniciar al boot
sudo systemctl disable servicio   # No iniciar al boot
```

---

## 📚 Practica

1. Instala nginx en tu VM
2. Verifica su estado con `systemctl status`
3. Detén nginx y verifica que no responde (`curl localhost`)
4. Inicia nginx y verifica que funciona
5. Habilita nginx para que inicie al encender el servidor
