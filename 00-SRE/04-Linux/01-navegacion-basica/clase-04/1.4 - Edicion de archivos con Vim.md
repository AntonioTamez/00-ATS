# Clase 1.4: Edición de Archivos con Vim

## 🎯 Objetivo
Aprender a editar archivos de texto directamente en la terminal usando Vim.

## ⏱️ Duración: 10-15 minutos

---

## ¿Por qué Vim?

Existen varios editores de texto en Linux, como `nano` (que es muy sencillo y parecido al bloc de notas) y `vi/vim`.

Aunque `nano` es fácil de usar, **Vim** es el estándar en la industria. Lo encontrarás en *todos* los servidores Linux, incluso en los más básicos donde no hay nada más. Por eso, en este curso usamos y recomendamos Vim.

---

## Modos de Vim

Vim es diferente a otros editores porque tiene **modos**. No puedes escribir texto apenas lo abres.

1. **Modo Normal** (Por defecto): Para moverte y dar comandos (guardar, salir).
2. **Modo Insertar**: Para escribir texto.

---

## Flujo de Trabajo Básico

### 1. Abrir un archivo

```bash
vim archivo.txt
```

### 2. Escribir texto (Modo Insertar)

Cuando abres Vim, estás en **Modo Normal**. Para escribir:
1. Presiona la tecla **`i`** (verás `-- INSERT --` abajo a la izquierda).
2. Escribe tu texto.
3. Para **salir** del modo insertar y volver al modo normal, presiona **`Esc`**.

> 💡 **Regla de oro:** Si no sabes en qué modo estás, presiona `Esc` un par de veces para volver al Modo Normal.

### 3. Guardar y Salir (Modo Normal)

Desde el Modo Normal (presiona `Esc` primero):

| Comando | Acción |
|---------|--------|
| `:wq` | **W**rite (guardar) y **Q**uit (salir). |
| `:x` | Igual que `:wq`, pero solo guarda si hubo cambios. |
| `:q!` | **Q**uit (salir) **!** (forzando) **SIN GUARDAR**. |

---

## Problemas Comunes: "No puedo guardar"

A veces intentas guardar (`:wq`) y Vim te da un error como `E45: 'readonly' option is set` o "Permission denied". Esto pasa porque no tienes permisos de escritura en el archivo.

### Solución

1. **Sal sin guardar**: Escribe `:q!` y presiona Enter.
2. **Arregla los permisos**:
    *   Si el archivo es tuyo, date permiso de escritura:
        ```bash
        chmod +w archivo.txt
        ```
    *   (Veremos más sobre permisos en el módulo de Usuarios y Permisos).
3. **O usa sudo**:
    *   Si el archivo es del sistema, ábrelo con superpoderes:
        ```bash
        sudo vim archivo.txt
        ```

---

## 📝 Resumen Comandos

```bash
i           # Entrar a modo insertar
Esc         # Salir a modo normal
:wq         # Guardar y salir
:x          # Guardar y salir (corto)
:q!         # Salir SIN guardar (pánico)
```

3. Guarda y sal con `:x`.
4. Vuelve a abrirlo, agrega otra línea.
5. Sal **sin guardar** con `:q!`.
