# Clase 1.3: Crear, Copiar, Mover y Eliminar

## 🎯 Objetivo
Dominar las operaciones CRUD de archivos y directorios en Linux.

## ⏱️ Duración: 15-20 minutos

---

## 📝 Guión de la Clase

### Intro (1 min)
"Hoy aprenderemos a manipular archivos y directorios. Son operaciones que harás cientos de veces, así que presta atención a los flags."

### Demo 1: Crear archivos y directorios (4 min)

```bash
# Crear directorio
mkdir mi_proyecto

# Crear estructura completa de una vez
mkdir -p mi_proyecto/src/components
mkdir -p mi_proyecto/{src,tests,docs}

# Ver lo que creamos
tree mi_proyecto
# Si no tienes tree: ls -R mi_proyecto

# Crear archivo vacío
touch mi_proyecto/README.md

# Crear archivo con contenido
echo "# Mi Proyecto" > mi_proyecto/README.md

# Agregar más contenido (sin sobrescribir)
echo "Descripción del proyecto" >> mi_proyecto/README.md
```

**Explicar**: 
- `>` sobrescribe el archivo
- `>>` agrega al final del archivo
- `-p` en mkdir crea toda la estructura de padres si no existe

### Demo 2: Copiar (4 min)

```bash
# Copiar archivo
cp mi_proyecto/README.md mi_proyecto/README.backup

# Copiar directorio (REQUIERE -r)
cp -r mi_proyecto mi_proyecto_backup

# Copiar preservando atributos
cp -rp original/ destino/

# Copiar múltiples archivos a un directorio
cp archivo1.txt archivo2.txt directorio/
```

**Explicar**: "Sin -r, cp no puede copiar directorios. Es el error más común de principiantes."

### Demo 3: Mover y Renombrar (3 min)

```bash
# Mover archivo
mv mi_proyecto/README.backup mi_proyecto/docs/

# Renombrar (es lo mismo que mover)
mv mi_proyecto/docs/README.backup mi_proyecto/docs/backup.md

# Mover directorio
mv mi_proyecto_backup/ ./
```

**Explicar**: "mv sirve tanto para mover como para renombrar. Si el destino es un nombre, renombra. Si es una ruta, mueve."

### Demo 4: Eliminar (⚠️ CUIDADO) (4 min)

```bash
# Eliminar archivo
rm archivo.txt

# Eliminar con confirmación
rm -i archivo.txt

# Eliminar directorio vacío
rmdir directorio_vacio/

# Eliminar directorio con contenido
rm -r directorio/

# Forzar eliminación (SIN CONFIRMACIÓN)
rm -rf directorio/
```

**⚠️ ADVERTENCIA IMPORTANTE**:
```bash
# NUNCA ejecutes esto:
# rm -rf /
# rm -rf /*
# rm -rf ~/*

# Siempre verifica antes de eliminar:
ls directorio/    # Ver qué hay
rm -ri directorio/ # Con confirmación
```

**Explicar**: "rm -rf es peligroso. No hay papelera de reciclaje en Linux. Lo que borras, se fue para siempre."

### Cierre (2 min)
"Ya dominas las operaciones básicas de archivos. Recuerda: siempre verifica antes de eliminar, especialmente con rm -rf."

## 💻 Comandos de la Clase

```bash
# Crear
mkdir directorio           # Crear directorio
mkdir -p padre/hijo/nieto  # Crear estructura completa
touch archivo.txt          # Crear archivo vacío
echo "texto" > archivo     # Crear con contenido
echo "más" >> archivo      # Agregar contenido

# Copiar
cp archivo.txt destino.txt      # Copiar archivo
cp -r directorio/ destino/      # Copiar directorio

# Mover/Renombrar
mv origen destino               # Mover o renombrar

# Eliminar
rm archivo.txt                  # Eliminar archivo
rm -r directorio/               # Eliminar directorio
rm -rf directorio/              # Forzar (¡CUIDADO!)
rmdir directorio_vacio/         # Solo directorios vacíos
```
