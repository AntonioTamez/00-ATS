# Clase 1.2: Ver Contenido de Archivos

## 🎯 Objetivo
Aprender diferentes formas de ver el contenido de archivos según el caso de uso.

## ⏱️ Duración: 15-20 minutos

---

## 📝 Guión de la Clase

### Intro (1 min)
"En DevOps constantemente necesitamos ver archivos: logs, configuraciones, scripts. Hoy aprenderemos las herramientas para cada situación."

### Demo 1: cat - Ver todo el archivo (3 min)

```bash
# Crear archivo de ejemplo
echo "Línea 1
Línea 2
Línea 3
Línea 4
Línea 5" > ejemplo.txt

# Ver todo el contenido
cat ejemplo.txt

# Ver con números de línea
cat -n ejemplo.txt
```

**Explicar**: "cat es perfecto para archivos pequeños. Para archivos grandes, es un problema porque te inunda la pantalla."

### Demo 2: head y tail (5 min)

```bash
# Ver primeras 10 líneas (por defecto)
head /var/log/syslog

# Ver primeras 5 líneas
head -n 5 /var/log/syslog

# Ver últimas 10 líneas
tail /var/log/syslog

# Ver últimas 20 líneas
tail -n 20 /var/log/syslog

# ⭐ IMPORTANTE: Seguir archivo en tiempo real
tail -f /var/log/syslog
```

**Explicar**: "tail -f es FUNDAMENTAL en DevOps. Lo usarás constantemente para monitorear logs en tiempo real. Ctrl+C para salir."

### Demo 3: less - Navegación interactiva (4 min)

```bash
# Abrir archivo para navegar
less /var/log/syslog
```

**Atajos dentro de less**:
```
Espacio     = Avanzar página
b           = Retroceder página
/texto      = Buscar "texto"
n           = Siguiente coincidencia
N           = Coincidencia anterior
g           = Ir al inicio
G           = Ir al final
q           = Salir
```

**Explicar**: "less es mejor que more porque permite retroceder. Recuerda: 'less is more'."

### Demo 4: Combinando comandos (3 min)

```bash
# Ver líneas 5-10 de un archivo
head -n 10 archivo.txt | tail -n 5

# Contar líneas de un archivo
wc -l /var/log/syslog

# Ver tamaño de archivo
ls -lh /var/log/syslog
```

### Cierre (2 min)
"Ahora tienes las herramientas para ver cualquier archivo. tail -f es tu mejor amigo para logs en producción."

---

## 💻 Comandos de la Clase

```bash
cat archivo.txt           # Ver todo
cat -n archivo.txt        # Con números de línea
head archivo.txt          # Primeras 10 líneas
head -n 5 archivo.txt     # Primeras 5 líneas
tail archivo.txt          # Últimas 10 líneas
tail -n 20 archivo.txt    # Últimas 20 líneas
tail -f archivo.txt       # Seguir en tiempo real ⭐
less archivo.txt          # Navegación interactiva
wc -l archivo.txt         # Contar líneas
```
