# Clase 1.1: Primeros Pasos en la Terminal

## 🎯 Objetivo
Familiarizarse con la terminal de Linux y los comandos básicos de navegación.

## ⏱️ Duración: 15-20 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"Bienvenidos al curso de Linux para DevOps. Hoy vamos a empezar desde lo más básico: la terminal. La terminal es tu mejor amiga en DevOps, aquí es donde pasarás el 90% de tu tiempo."

### Demo 1: ¿Dónde estoy? (3 min)

```bash
# Ver en qué directorio estamos
pwd
# Output: /home/usuario

# Ver quién soy
whoami
# Output: usuario

# Ver información del sistema
uname -a
```

**Explicar**: "pwd = Print Working Directory. Siempre que te sientas perdido, usa pwd."

### Demo 2: Listar archivos (5 min)

```bash
# Listar básico
ls

# Listar con detalles
ls -l

# Listar TODO (incluyendo ocultos)
ls -a

# El comando estrella: ls -alh
ls -alh
```

**Explicar cada columna**:
```
drwxr-xr-x 2 usuario grupo 4.0K Jan 15 10:30 directorio
-rw-r--r-- 1 usuario grupo  156 Jan 15 10:30 archivo.txt
│└─┬──┘└─┬─┘ │   │      │    │      │        └── Nombre
│  │     │   │   │      │    │      └── Fecha modificación
│  │     │   │   │      │    └── Tamaño (h = human readable)
│  │     │   │   │      └── Grupo
│  │     │   │   └── Propietario
│  │     │   └── Links
│  │     └── Permisos otros
│  └── Permisos grupo
└── Tipo (d=directorio, -=archivo, l=link)
```

### Demo 3: Moverse entre directorios (5 min)

```bash
# Ir a un directorio
cd /var/log

# Verificar
pwd

# Volver al home
cd ~
# o simplemente
cd

# Subir un nivel
cd ..

# Volver al directorio anterior
cd -
```

**Tip**: "El tabulador es tu amigo. Escribe 'cd /va' y presiona TAB para autocompletar."

### Cierre (2 min)
"Ya sabes moverte por el sistema. En la siguiente clase veremos cómo ver el contenido de archivos y crear directorios."

---

## 💻 Comandos de la Clase

```bash
pwd                 # Directorio actual
whoami              # Usuario actual
uname -a            # Info del sistema
ls                  # Listar archivos
ls -l               # Listar con detalles
ls -a               # Incluir ocultos
ls -alh             # Todo + tamaños legibles
cd /ruta            # Cambiar directorio
cd ~                # Ir al home
cd ..               # Subir un nivel
cd -                # Directorio anterior
```

2. Navegar a `/etc` y listar su contenido
3. Volver al home con `cd ~`
