# Clase 8.2: DNS con dig

## 🎯 Objetivo
Aprender a diagnosticar y verificar DNS con dig.

## ⏱️ Duración: 15-20 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"Configuraste tu dominio pero no resuelve. ¿Propagó el DNS? dig te dice exactamente qué está pasando con la resolución de nombres."

### Setup (1 min)

```bash
# Instalar dnsutils si no está
sudo apt install -y dnsutils

# Verificar
dig -v
```

### Demo 1: Consulta básica (3 min)

```bash
# Consulta completa
dig google.com

# Secciones de la respuesta:
# QUESTION SECTION  = Lo que preguntaste
# ANSWER SECTION    = La respuesta (IPs)
# AUTHORITY SECTION = Servidores DNS autoritativos
# Query time        = Tiempo de respuesta

# Solo la respuesta (lo más útil)
dig +short google.com
```

### Demo 2: Tipos de registros (5 min)

```bash
# Registro A (IPv4)
dig +short google.com A

# Registro AAAA (IPv6)
dig +short google.com AAAA

# Registro MX (servidores de correo)
dig +short google.com MX

# Registro NS (servidores DNS)
dig +short google.com NS

# Registro TXT (verificaciones, SPF, etc.)
dig +short google.com TXT

# Registro CNAME (alias)
dig +short www.github.com CNAME

# Todos los registros
dig google.com ANY
```

### Demo 3: Consultar DNS específico (3 min)

```bash
# Usar servidor DNS de Google
dig @8.8.8.8 +short mi-dominio.com

# Usar servidor DNS de Cloudflare
dig @1.1.1.1 +short mi-dominio.com

# Útil para verificar propagación
# Si respuestas son diferentes = Aún propagando

# Consultar DNS autoritativo directamente
dig +short NS mi-dominio.com
# Luego consultar ese servidor
dig @ns1.ejemplo.com +short mi-dominio.com
```

### Demo 4: Reverse DNS (2 min)

```bash
# Buscar nombre de una IP
dig -x 8.8.8.8
dig -x 8.8.8.8 +short
# Output: dns.google.
```

### Demo 5: Casos prácticos DevOps (4 min)

```bash
# Verificar que CNAME del Load Balancer está configurado
dig +short CNAME app.mi-empresa.com
# Debe apuntar a: algo.elb.amazonaws.com

# Verificar registro A de CDN
dig +short cdn.mi-empresa.com

# Verificar propagación DNS en múltiples ubicaciones
dig @8.8.8.8 +short mi-dominio.com
dig @1.1.1.1 +short mi-dominio.com
dig @208.67.222.222 +short mi-dominio.com  # OpenDNS

# TTL del registro (tiempo de cache)
dig mi-dominio.com | grep -A1 "ANSWER SECTION"
# El número antes de "IN" es el TTL en segundos
```

### Cierre (2 min)
"dig +short es tu mejor amigo para troubleshooting de DNS. Siempre verifica propagación desde diferentes servidores DNS."

---

## 💻 Comandos de la Clase

```bash
dig dominio.com                    # Consulta completa
dig +short dominio.com             # Solo respuesta
dig +short dominio.com A           # Registro A
dig +short dominio.com MX          # Registros de correo
dig +short dominio.com NS          # Servidores DNS
dig +short dominio.com TXT         # Registros TXT
dig +short dominio.com CNAME       # Alias
dig @8.8.8.8 +short dominio.com    # Usar DNS específico
dig -x IP                          # Reverse DNS
dig +trace dominio.com             # Trace completo
```

---

## 📋 Tipos de Registros DNS

| Tipo | Uso |
|------|-----|
| A | IPv4 del dominio |
| AAAA | IPv6 del dominio |
| CNAME | Alias (apunta a otro dominio) |
| MX | Servidores de correo |
| NS | Servidores DNS autoritativos |
| TXT | Texto (SPF, verificaciones) |
| SOA | Info de la zona |
