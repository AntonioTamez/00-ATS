# Clase 10.1: Compresión y Archivado con tar

## 🎯 Objetivo
Dominar tar para crear, extraer y comprimir archivos.

## ⏱️ Duración: 15-20 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"tar es la herramienta estándar para backups y transferencia de archivos en Linux. Combina archivado (juntar archivos) con compresión."

### Demo 1: Crear archivos tar (4 min)

```bash
# Crear directorio de prueba
mkdir -p ./proyecto/{src,docs,config}
echo "código" > ./proyecto/src/app.js
echo "readme" > ./proyecto/docs/README.md
echo "config" > ./proyecto/config/settings.json

# Crear archivo tar (sin compresión)
tar -cvf proyecto.tar ./proyecto/
# c = create
# v = verbose
# f = filename

# Crear tar.gz (comprimido con gzip)
tar -czvf proyecto.tar.gz ./proyecto/
# z = gzip

# Crear tar.bz2 (mejor compresión)
tar -cjvf proyecto.tar.bz2 ./proyecto/
# j = bzip2

# Ver tamaños
ls -lh proyecto.tar*
```

### Demo 2: Extraer archivos (4 min)

```bash
# Extraer tar
tar -xvf proyecto.tar
# x = extract

# Extraer tar.gz
tar -xzvf proyecto.tar.gz

# Extraer en directorio específico
tar -xzvf proyecto.tar.gz -C ./destino/

# Extraer archivo específico
tar -xzvf proyecto.tar.gz tmp/proyecto/src/app.js
```

### Demo 3: Listar contenido (2 min)

```bash
# Ver contenido sin extraer
tar -tvf proyecto.tar.gz

# Buscar archivo específico
tar -tvf proyecto.tar.gz | grep app.js
```

### Demo 4: Casos prácticos (4 min)

```bash
# Backup con fecha
FECHA=$(date +%Y%m%d_%H%M%S)
tar -czvf backup_${FECHA}.tar.gz /opt/mi-app/

# Excluir archivos
tar -czvf backup.tar.gz /opt/mi-app/ --exclude='*.log' --exclude='node_modules'

# Backup incremental (archivos modificados)
tar -czvf backup.tar.gz /opt/mi-app/ --newer-mtime="2024-01-01"
```

### Demo 5: zip/unzip (alternativa) (2 min)

```bash
# Crear zip
zip -r proyecto.zip ./proyecto/

# Extraer zip
unzip proyecto.zip

# Extraer en directorio
unzip proyecto.zip -d ./destino/

# Listar contenido
unzip -l proyecto.zip
```

### Cierre (2 min)
"tar -czvf para crear, tar -xzvf para extraer. Con eso cubres el 90% de los casos."

---

## 💻 Comandos de la Clase

```bash
# Crear
tar -cvf archivo.tar directorio/       # Sin compresión
tar -czvf archivo.tar.gz directorio/   # Con gzip
tar -cjvf archivo.tar.bz2 directorio/  # Con bzip2

# Extraer
tar -xvf archivo.tar
tar -xzvf archivo.tar.gz
tar -xzvf archivo.tar.gz -C /destino/

# Listar
tar -tvf archivo.tar.gz

# Zip
zip -r archivo.zip directorio/
unzip archivo.zip
```

---

## 📋 Flags de tar

| Flag | Significado |
|------|-------------|
| c | Create (crear) |
| x | Extract (extraer) |
| t | List (listar) |
| v | Verbose |
| f | File (archivo) |
| z | gzip |
| j | bzip2 |
| C | Directorio destino |
