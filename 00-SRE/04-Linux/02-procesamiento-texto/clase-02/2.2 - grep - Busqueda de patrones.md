# Clase 2.2: grep - Búsqueda de Patrones

## 🎯 Objetivo
Dominar grep para buscar texto en archivos, esencial para análisis de logs.

## ⏱️ Duración: 20-25 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"grep es probablemente el comando que más usarás en DevOps. Cada vez que busques un error en logs, cada vez que busques una configuración, usarás grep."

### Demo 1: Búsqueda básica (4 min)

```bash
# Buscar texto simple
grep "ERROR" access.log

# Buscar código de estado 500
grep "500" access.log

# Buscar IP específica
grep "192.168.1.100" access.log
```

### Demo 2: Flags esenciales (6 min)

```bash
# -i: Ignorar mayúsculas/minúsculas
grep -i "error" access.log

# -v: Invertir (líneas que NO contienen)
grep -v "200" access.log

# -n: Mostrar número de línea
grep -n "ERROR" access.log

# -c: Contar coincidencias
grep -c "200" access.log

# Combinar flags
grep -in "error" access.log
```

### Demo 3: Contexto (3 min)

```bash
# -A: Mostrar líneas DESPUÉS (After)
grep -A 2 "ERROR" access.log

# -B: Mostrar líneas ANTES (Before)
grep -B 2 "ERROR" access.log

# -C: Mostrar líneas ANTES y DESPUÉS (Context)
grep -C 2 "ERROR" access.log
```

**Explicar**: "Esto es SUPER útil para ver qué pasó antes y después de un error."

### Demo 4: Búsqueda recursiva (3 min)

```bash
# Crear estructura de ejemplo
mkdir -p proyecto/{src,config}
echo "DATABASE_URL=postgres://localhost" > proyecto/config/db.conf
echo "API_KEY=secret123" > proyecto/config/api.conf
echo "// TODO: fix this bug" > proyecto/src/app.js

# Buscar recursivamente en directorio
grep -r "TODO" proyecto/
grep -r "secret" proyecto/
```

### Demo 5: Expresiones regulares básicas (4 min)

```bash
# ^ = Inicio de línea
grep "^ERROR" access.log

# $ = Fin de línea
grep "200$" access.log  # No funciona porque hay más texto
grep "detected$" access.log

# Escapar caracteres especiales
grep "192\.168\." access.log

# -E: Expresiones extendidas (múltiples patrones)
grep -E "ERROR|WARNING" access.log
grep -E "500|404" access.log
```

### Cierre (2 min)
"grep es tu detective de logs. Practica mucho porque lo usarás a diario."

## 💻 Comandos de la Clase

```bash
grep "texto" archivo           # Búsqueda básica
grep -i "texto" archivo        # Ignorar mayúsculas
grep -v "texto" archivo        # Invertir (NO contiene)
grep -n "texto" archivo        # Número de línea
grep -c "texto" archivo        # Contar
grep -r "texto" directorio/    # Recursivo
grep -A 3 "texto" archivo      # 3 líneas después
grep -B 3 "texto" archivo      # 3 líneas antes
grep -C 3 "texto" archivo      # 3 líneas contexto
grep -E "a|b" archivo          # Múltiples patrones
grep "^inicio" archivo         # Empieza con
grep "fin$" archivo            # Termina con
```
