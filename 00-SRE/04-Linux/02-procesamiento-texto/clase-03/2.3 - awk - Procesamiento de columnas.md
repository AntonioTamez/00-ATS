# Clase 2.3: awk - Procesamiento de Columnas

## 🎯 Objetivo
Aprender a extraer y procesar datos por columnas con awk.

## ⏱️ Duración: 20-25 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"awk es como Excel en la terminal. Cuando tienes datos en columnas y necesitas extraer o procesar campos específicos, awk es tu herramienta."

### Setup: Crear archivos de práctica (2 min)

```bash
# Log de acceso estilo nginx
cat << 'EOF' > ./nginx.log
192.168.1.100 GET /api/users 200 0.045
192.168.1.101 POST /api/login 200 0.123
10.0.0.50 GET /api/products 500 2.456
192.168.1.100 GET /api/orders 200 0.089
10.0.0.51 POST /api/checkout 404 0.034
192.168.1.102 GET /health 200 0.012
192.168.1.100 DELETE /api/users/5 500 1.234
192.168.1.102 GET /health 200 0.012
192.168.1.100 DELETE /api/users/5 500 1.234
EOF

# Archivo CSV
cat << 'EOF' > ./servers.csv
nombre,ip,cpu,memoria
web-server-1,192.168.1.10,45,2048
web-server-2,192.168.1.11,78,4096
db-server-1,192.168.1.20,92,8192
cache-server,192.168.1.30,15,1024
EOF
```

### Demo 1: Imprimir columnas (5 min)

```bash
# Imprimir primera columna (IPs)
awk '{print $1}' ./nginx.log

# Imprimir múltiples columnas
awk '{print $1, $4}' ./nginx.log

# Imprimir última columna
awk '{print $NF}' ./nginx.log

# Imprimir penúltima columna
awk '{print $(NF-1)}' ./nginx.log

# Toda la línea
awk '{print $0}' ./nginx.log
```

**Explicar**: 
- `$1, $2, $3...` = columnas
- `$NF` = última columna (Number of Fields)
- `$0` = toda la línea

### Demo 2: Cambiar separador (4 min)

```bash
# Por defecto awk usa espacios como separador
# Para CSV necesitamos coma:
awk -F',' '{print $1}' ./servers.csv

# Imprimir nombre e IP
awk -F',' '{print $1, $2}' ./servers.csv

# Para /etc/passwd (separador :)
awk -F':' '{print $1}' /etc/passwd | head -5
```

### Demo 3: Filtrar con condiciones (5 min)

```bash
# Filtrar por valor de columna
awk '$4 == 500 {print $0}' ./nginx.log

# Filtrar por comparación numérica
awk '$5 > 1 {print $1, $3, $5}' ./nginx.log

# Filtrar por patrón (como grep)
awk '/GET/ {print $0}' ./nginx.log

# Combinar condiciones
awk '$4 == 500 && $5 > 1 {print $1, $3}' ./nginx.log
```

### Demo 4: Operaciones matemáticas (4 min)

```bash
# Sumar columna (tiempo de respuesta)
awk '{sum += $5} END {print "Total:", sum}' ./nginx.log

# Calcular promedio
awk '{sum += $5; count++} END {print "Promedio:", sum/count}' ./nginx.log

# Contar líneas con condición
awk '$4 == 500 {count++} END {print "Errores 500:", count}' ./nginx.log
```

**Explicar**: 
- `END` = ejecutar después de procesar todas las líneas
- `BEGIN` = ejecutar antes de procesar

### Demo 5: Formatear salida (3 min)

```bash
# Agregar texto
awk '{print "IP:", $1, "- Status:", $4}' ./nginx.log

# Formato con printf
awk '{printf "%-20s %s\n", $1, $4}' ./nginx.log

# Crear formato CSV
awk '{print $1","$3","$4}' ./nginx.log
```

### Caso Práctico: Top IPs por requests (3 min)

```bash
# Contar requests por IP (combo poderoso)
awk '{print $1}' ./nginx.log | sort | uniq -c | sort -rn

# Desglose:
# awk '{print $1}'  -> Extrae IPs
# sort              -> Ordena alfabéticamente (necesario para uniq)
# uniq -c           -> Cuenta repeticiones
# sort -rn          -> Ordena numéricamente en reversa
```

### Cierre (2 min)
"awk + sort + uniq es un combo muy poderoso para análisis de logs. Practícalo mucho."

## 💻 Comandos de la Clase

```bash
awk '{print $1}' archivo           # Primera columna
awk '{print $1, $3}' archivo       # Columnas 1 y 3
awk '{print $NF}' archivo          # Última columna
awk -F',' '{print $1}' archivo     # Separador coma
awk -F':' '{print $1}' archivo     # Separador :
awk '$3 > 100' archivo             # Filtrar por condición
awk '/patron/' archivo             # Filtrar por patrón
awk '{sum+=$1} END {print sum}'    # Sumar columna
awk '{print $1}' | sort | uniq -c  # Contar únicos
```
