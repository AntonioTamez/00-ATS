# Clase 2.5: stdin, stdout y stderr

## 🎯 Objetivo
Entender los 3 flujos estándar de entrada/salida en Linux.

## ⏱️ Duración: 5-7 minutos

---

## 📝 Contenido

### ¿Qué son los flujos estándar?

Todo comando en Linux tiene 3 canales de comunicación:

```
┌─────────────┐
│   COMANDO   │
└─────────────┘
      │
      ├── stdin  (0) ← Entrada estándar (teclado)
      ├── stdout (1) → Salida estándar (pantalla)
      └── stderr (2) → Salida de errores (pantalla)
```

| Flujo | Número | Descripción | Por defecto |
|-------|--------|-------------|-------------|
| stdin | 0 | Entrada de datos | Teclado |
| stdout | 1 | Salida normal | Pantalla |
| stderr | 2 | Mensajes de error | Pantalla |

---

### Demo 1: stdout - Salida estándar

```bash
# Este comando produce salida normal (stdout)
echo "Hola mundo"
ls /home

# La salida va a la pantalla por defecto
```

---

### Demo 2: stderr - Salida de errores

```bash
# Este comando produce un error (stderr)
ls /carpeta_que_no_existe

# El error también va a la pantalla, pero es un flujo diferente
```

---

### Demo 3: Separar stdout y stderr

```bash
# Redirigir solo stdout a un archivo
ls /home /noexiste > salida.txt
# Los errores siguen apareciendo en pantalla

# Redirigir solo stderr a un archivo
ls /home /noexiste 2> errores.txt
# La salida normal aparece en pantalla

# Redirigir cada uno a su archivo
ls /home /noexiste > salida.txt 2> errores.txt

# Verificar
cat salida.txt
cat errores.txt
```

---

### Demo 4: Combinar stdout y stderr

```bash
# Enviar ambos al mismo archivo
ls /home /noexiste > todo.txt 2>&1

# Forma moderna (bash)
ls /home /noexiste &> todo.txt

# Verificar
cat todo.txt
```

**Explicación de `2>&1`:**
- `2>` = redirigir stderr
- `&1` = al mismo lugar que stdout

---

### Demo 5: Descartar salida

```bash
# Descartar stdout (solo ver errores)
ls /home /noexiste > /dev/null

# Descartar stderr (solo ver salida normal)
ls /home /noexiste 2> /dev/null

# Descartar TODO (silencio total)
ls /home /noexiste > /dev/null 2>&1
# o
ls /home /noexiste &> /dev/null
```

**¿Qué es `/dev/null`?**
Es un "agujero negro" - todo lo que envías ahí desaparece.

---

### Demo 6: stdin - Entrada estándar

```bash
# Leer desde teclado
cat
# (escribe algo y presiona Enter, Ctrl+D para terminar)

# Leer desde archivo (redirigir stdin)
cat < archivo.txt

# Contar líneas desde stdin
wc -l < archivo.txt
```

---

## 📋 Resumen Rápido

```bash
comando > archivo       # stdout a archivo
comando 2> archivo      # stderr a archivo
comando &> archivo      # ambos a archivo
comando > /dev/null     # descartar stdout
comando 2> /dev/null    # descartar stderr
comando &> /dev/null    # descartar todo
comando < archivo       # leer stdin desde archivo
```

---

## 💡 ¿Por qué es importante?

1. **Scripts**: Guardar logs y separar errores
2. **Cron jobs**: Capturar errores para debugging
3. **Pipelines**: Filtrar solo lo que necesitas
4. **Silenciar ruido**: Ignorar mensajes que no te interesan

---

## 📚 Practica

1. Ejecuta `ls /home /noexiste` y observa ambas salidas
2. Redirige solo los errores a `errores.txt`
3. Redirige solo la salida exitosa a `exito.txt`
4. Descarta completamente la salida con `/dev/null`
