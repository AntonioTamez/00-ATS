# Clase 2.1: Heredocs - Crear Archivos Multilínea

## 🎯 Objetivo
Aprender a crear archivos de texto multilínea desde la terminal usando Heredocs.

## ⏱️ Duración: 10-15 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"Antes de entrar al procesamiento de texto, necesitamos saber cómo crear archivos de práctica rápidamente. Los Heredocs nos permiten crear archivos multilínea directamente en la terminal, sin abrir ningún editor."

### Demo 1: ¿Qué es un Heredoc? (3 min)

```bash
# Heredoc = "Here Document" (Documento Aquí)
# Permite escribir múltiples líneas de texto y enviarlas a un comando

# Estructura básica:
# comando << LIMITADOR
# contenido
# contenido
# LIMITADOR

# Ejemplo: Mostrar texto multilínea
cat << EOF
Línea 1
Línea 2
Línea 3
EOF
```

**Explicar**:
- `<<` le dice a Bash: "voy a enviarte un bloque de texto"
- `EOF` es el limitador (marca inicio y fin)
- Todo lo que está entre los dos `EOF` se envía al comando
- `EOF` significa "End Of File" pero es solo una convención

### Demo 2: Crear archivos con Heredoc (4 min)

```bash
# Crear archivo (sobrescribe si existe)
cat << EOF > mi_archivo.txt
Este es un archivo
creado con heredoc
tiene múltiples líneas
EOF

# Verificar
cat mi_archivo.txt

# Agregar al final del archivo (append)
cat << EOF >> mi_archivo.txt
Esta línea se agrega
al final del archivo
EOF

# Verificar
cat mi_archivo.txt
```

**Explicar**:
- `>` sobrescribe el archivo
- `>>` agrega al final sin borrar lo anterior

### Demo 3: Con comillas vs Sin comillas (5 min)

```bash
# Definir una variable
NOMBRE="Jean"

# $(...) = Sustitución de comandos
# Ejecuta el comando dentro del paréntesis y guarda el resultado
FECHA=$(date)
echo $FECHA
# Output: Thu Jan 1 10:30:00 UTC 2026

# Otros ejemplos de sustitución de comandos:
USUARIO=$(whoami)      # Guarda el nombre de usuario
ARCHIVOS=$(ls)         # Guarda la lista de archivos
LINEAS=$(wc -l < archivo.txt)  # Guarda el número de líneas

# SIN comillas - Bash EXPANDE variables
cat << EOF
Hola $NOMBRE
Fecha: $FECHA
Home: $HOME
EOF
# Resultado: Hola Jean, Fecha: Thu Jan 1..., Home: /home/usuario

# CON comillas simples - Texto LITERAL (no expande nada)
cat << 'EOF'
Hola $NOMBRE
Fecha: $FECHA
Home: $HOME
EOF
# Resultado: Hola $NOMBRE, Fecha: $FECHA, Home: $HOME (literal)
```

**IMPORTANTE**: 
- `'EOF'` con comillas = texto literal, ideal para:
  - Logs de ejemplo
  - Archivos de configuración
  - JSON/YAML
  - Scripts
  - Expresiones regulares

### Demo 4: El limitador puede ser cualquier palabra (2 min)

```bash
# No tiene que ser EOF, puede ser cualquier palabra
cat << FIN
Contenido aquí
FIN

cat << TEXTO
Otro contenido
TEXTO

cat << __CONFIG__
server=localhost
port=8080
__CONFIG__

# Reglas del limitador:
# - Debe ser la misma palabra al inicio y al final
# - Debe estar sola en la línea (sin espacios antes)
# - EOF es solo una convención popular
```

## 💻 Comandos de la Clase

```bash
# Crear archivo (sobrescribe)
cat << EOF > archivo.txt
contenido
EOF

# Agregar al archivo (append)
cat << EOF >> archivo.txt
más contenido
EOF

# Texto literal (no expande variables)
cat << 'EOF' > archivo.txt
$VARIABLE se mantiene literal
EOF

# Limitador personalizado
cat << MI_LIMITE > archivo.txt
contenido
MI_LIMITE
```

---

## 📋 Resumen Rápido

| Sintaxis | Comportamiento |
|----------|----------------|
| `<< EOF` | Expande variables `$VAR` |
| `<< 'EOF'` | Texto literal (no expande) |
| `> archivo` | Sobrescribe archivo |
| `>> archivo` | Agrega al final |

---

## ⚠️ Errores Comunes

```bash
# ❌ ERROR: Espacio antes del limitador final
cat << EOF > archivo.txt
contenido
  EOF    # <-- Tiene espacios, no funciona

# ✅ CORRECTO: Limitador solo, sin espacios
cat << EOF > archivo.txt
contenido
EOF

# ❌ ERROR: Limitadores diferentes
cat << EOF > archivo.txt
contenido
END      # <-- Diferente a EOF

# ✅ CORRECTO: Mismo limitador
cat << EOF > archivo.txt
contenido
EOF
```
