# Clase 2.4: sed - Editor de Flujos

## 🎯 Objetivo
Aprender a hacer búsqueda y reemplazo de texto con sed.

## ⏱️ Duración: 15-20 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"sed es tu herramienta de búsqueda y reemplazo en la terminal. En DevOps lo usarás para modificar archivos de configuración de forma automatizada."

### Setup: Crear archivo de práctica (1 min)

```bash
# Archivo de configuración de ejemplo
cat << 'EOF' > ./app.conf
# Application Configuration
APP_NAME=MyApp
APP_ENV=development
APP_DEBUG=true
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_NAME=myapp_dev
CACHE_DRIVER=file
LOG_LEVEL=debug
EOF
```

### Demo 1: Sustitución básica (4 min)

```bash
# Reemplazar primera ocurrencia por línea
sed 's/development/production/' ./app.conf

# Reemplazar TODAS las ocurrencias (flag g = global)
sed 's/localhost/db.server.com/g' ./app.conf

# El archivo original NO cambia (sed muestra el resultado)
cat ./app.conf
```

**Explicar**: "Por defecto sed solo muestra el resultado. El archivo original no cambia."

### Demo 2: Edición in-situ (3 min)

```bash
# Crear copia para practicar
cp ./app.conf ./app.conf.test

# Editar el archivo directamente (-i)
sed -i 's/development/production/' ./app.conf.test

# Verificar cambio
cat ./app.conf.test

# Crear backup antes de editar
sed -i.bak 's/debug/info/' ./app.conf.test

# Ver backup creado
ls -la ./app.conf.test*
```

**Explicar**: "-i modifica el archivo. -i.bak crea backup automático. Siempre usa backup en producción."

### Demo 3: Ignorar mayúsculas y otros flags (3 min)

```bash
# Restaurar archivo original
cp ./app.conf ./app.conf.test

# Ignorar mayúsculas/minúsculas
sed 's/myapp/PRODUCCION/gi' ./app.conf.test

# Solo en líneas que coincidan con patrón
sed '/DATABASE/s/localhost/db.prod.com/' ./app.conf.test
```

### Demo 4: Eliminar líneas (3 min)

```bash
# Eliminar líneas que contienen patrón
sed '/^#/d' ./app.conf       # Eliminar comentarios
sed '/DEBUG/d' ./app.conf    # Eliminar línea con DEBUG
sed '/^$/d' ./app.conf       # Eliminar líneas vacías

# Eliminar línea específica por número
sed '1d' ./app.conf          # Eliminar primera línea
sed '1,3d' ./app.conf        # Eliminar líneas 1-3
```

### Demo 5: Casos prácticos DevOps (4 min)

```bash
# Cambiar puerto en configuración
sed -i 's/DATABASE_PORT=5432/DATABASE_PORT=5433/' ./app.conf.test

# Cambiar múltiples valores con múltiples sed
sed -e 's/development/production/' \
    -e 's/localhost/prod-db.server.com/' \
    -e 's/debug/error/' \
    ./app.conf

# Comentar una línea (agregar # al inicio)
sed 's/^APP_DEBUG/#APP_DEBUG/' ./app.conf

# Descomentar una línea
sed 's/^#APP_DEBUG/APP_DEBUG/' ./app.conf

# Agregar línea después de patrón
sed '/APP_ENV/a NEW_VAR=value' ./app.conf

# Agregar línea antes de patrón
sed '/APP_ENV/i ANOTHER_VAR=test' ./app.conf
```

### Cierre (2 min)
"sed es esencial para automatización. Cuando escribas scripts que modifiquen configuraciones, sed será tu herramienta principal."

---

## 💻 Comandos de la Clase

```bash
sed 's/viejo/nuevo/' archivo           # Reemplazar (primera ocurrencia)
sed 's/viejo/nuevo/g' archivo          # Reemplazar todas
sed 's/viejo/nuevo/gi' archivo         # Ignorar mayúsculas
sed -i 's/viejo/nuevo/g' archivo       # Editar archivo directamente
sed -i.bak 's/viejo/nuevo/g' archivo   # Con backup
sed '/patron/d' archivo                # Eliminar líneas con patrón
sed '/^#/d' archivo                    # Eliminar comentarios
sed '/^$/d' archivo                    # Eliminar líneas vacías
sed '1d' archivo                       # Eliminar primera línea
sed -e 's/a/b/' -e 's/c/d/' archivo    # Múltiples sustituciones
sed '/patron/s/viejo/nuevo/' archivo   # Solo en líneas con patrón
```
