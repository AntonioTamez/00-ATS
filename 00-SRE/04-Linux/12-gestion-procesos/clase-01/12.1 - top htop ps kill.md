# Clase 12.1: Gestión de Procesos

## 🎯 Objetivo
Ver procesos en ejecución y terminarlos cuando sea necesario.

## ⏱️ Duración: 5-7 minutos

---

## Ver Procesos con `ps`

### Procesos del usuario actual
```bash
ps
```

### Todos los procesos con detalles
```bash
ps aux
```

**Columnas importantes:**
- `USER` - Usuario dueño
- `PID` - ID del proceso (lo necesitas para matar)
- `%CPU` - Uso de CPU
- `%MEM` - Uso de memoria
- `COMMAND` - Qué es el proceso

### Buscar proceso específico
```bash
ps aux | grep nginx
```

### Ver árbol de procesos
```bash
ps fax
```

---

## Monitor en Tiempo Real: `top`

```bash
top
```

**Atajos dentro de top:**
- `q` - Salir
- `M` - Ordenar por memoria
- `P` - Ordenar por CPU
- `k` - Matar proceso (pide PID)

---

## Monitor Mejorado: `htop`

```bash
# Instalar si no está
sudo apt install htop   # Ubuntu
sudo yum install htop   # Amazon Linux

# Ejecutar
htop
```

**Atajos en htop:**
- `F10` o `q` - Salir
- `F5` - Ver árbol de procesos
- `F6` - Cambiar ordenamiento
- `F9` - Matar proceso

htop es más visual e intuitivo que top.

---

## Matar Procesos

### Por PID
```bash
# Terminación normal (permite limpiar)
kill 12345

# Terminación forzada (inmediato)
kill -9 12345
```

### Por nombre
```bash
killall nginx
pkill nginx
```

---

## Diferencia: kill vs kill -9

| Señal | Descripción |
|-------|-------------|
| `kill PID` | "Por favor termina" - El proceso puede limpiar |
| `kill -9 PID` | "Muere ahora" - Forzado, no puede ignorarse |

**Regla:** Primero intenta `kill`, si no funciona usa `kill -9`.

---

## Encontrar y Matar un Proceso

```bash
# 1. Buscar el proceso
ps aux | grep nombre_proceso

# 2. Anotar el PID (segunda columna)

# 3. Matarlo
kill PID

# Si no muere:
kill -9 PID
```

---

## 📋 Resumen

```bash
ps aux                  # Ver todos los procesos
ps aux | grep proceso   # Buscar proceso
ps fax                  # Ver árbol
top                     # Monitor en tiempo real
htop                    # Monitor mejorado
kill PID                # Terminar proceso
kill -9 PID             # Forzar terminación
killall nombre          # Matar por nombre
```

## 📚 Practica

1. Lista todos los procesos con `ps aux`

3. Abre `htop` y explora la interfaz
4. Ordena por uso de memoria
5. Crea un proceso de prueba (`sleep 1000 &`) y mátalo
