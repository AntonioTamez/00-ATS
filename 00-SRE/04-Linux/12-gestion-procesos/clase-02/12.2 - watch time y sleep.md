# Clase 12.2: watch, time y sleep

## 🎯 Objetivo
Monitorear comandos en tiempo real, medir cuánto tarda un comando y pausar la ejecución.

## ⏱️ Duración: 8-10 minutos

---

## 📝 Guión de la Clase

### Intro (1 min)
"Tres comandos pequeños pero muy útiles en DevOps: `watch` para ver cambios en vivo, `time` para medir tiempos y `sleep` para esperar."

### Demo 1: watch (3 min)

```bash
# Repetir un comando cada 2 segundos (por defecto)
watch date

# Monitorear espacio en disco
watch df -h

# Cambiar intervalo (cada 5 segundos)
watch -n 5 ps aux

# Resaltar lo que cambió entre ejecuciones
watch -d ls -la

# Salir: Ctrl+C
```

**Explicar**: "`watch` ejecuta el mismo comando una y otra vez. Ideal para ver logs, procesos o disco sin escribir el comando manualmente."

### Demo 2: time (2 min)

```bash
# Medir cuánto tarda un comando
time ls -R /usr

# Medir un comando de red
time curl -s https://example.com > /dev/null

# Medir un script
time ./mi_script.sh
```

**Explicar**: "Muestra tres tiempos: `real` (reloj de pared), `user` (CPU en tu proceso) y `sys` (CPU del sistema). Lo más útil suele ser `real`."

### Demo 3: sleep (2 min)

```bash
# Pausar 3 segundos
sleep 3

# Esperar y luego ejecutar algo
sleep 5 && echo "Listo"

# En segundo plano (no bloquea la terminal)
sleep 30 &
```

**Explicar**: "`sleep` espera N segundos. Lo usarás en scripts, pruebas y para simular procesos largos."

### Cierre (1 min)
"Usa `watch` para monitorear, `time` para medir rendimiento y `sleep` para pausas en scripts o pruebas."

---

## 💻 Comandos de la Clase

```bash
watch comando             # Repetir comando cada 2 s
watch -n 5 comando        # Cambiar intervalo
watch -d comando          # Resaltar cambios
time comando              # Medir tiempo de ejecución
sleep 5                   # Pausar 5 segundos
sleep 30 &                # Pausar en segundo plano
```

## 📚 Tarea para el Estudiante
1. Usa `watch df -h` y observa el disco durante unos segundos (Ctrl+C para salir).
2. Mide con `time` cuánto tarda `sleep 2`.
3. Ejecuta `sleep 10 &`, luego `ps aux | grep sleep` y mata el proceso con `kill`.
