# Clase 5.3: Ejecutar Scripts - Con y Sin Bash

## 🎯 Objetivo
Entender las diferencias entre las formas de ejecutar scripts.

## ⏱️ Duración: 5 minutos

---

## Las 3 Formas de Ejecutar un Script

```bash
# 1. Con el comando bash
bash script.sh

# 2. Directamente (necesita +x)
./script.sh

# 3. Con source (se ejecuta en la shell actual)
source script.sh
```

---

## Método 1: `bash script.sh`

```bash
bash mi_script.sh
```

**Características:**
- ✅ No necesita permisos de ejecución
- ✅ No necesita shebang
- ✅ Ideal para pruebas rápidas
- ❌ Tienes que escribir `bash` cada vez

**Cuándo usarlo:** Para probar scripts mientras los desarrollas.

---

## Método 2: `./script.sh`

```bash
chmod +x mi_script.sh
./mi_script.sh
```

**Características:**
- ✅ Más profesional
- ✅ El script es "autoejecutable"
- ✅ Usa el intérprete del shebang
- ❌ Necesita `chmod +x` primero

**Cuándo usarlo:** Para scripts que usarás frecuentemente.

---

## Método 3: `source script.sh`

```bash
source mi_script.sh
# o su alias:
. mi_script.sh
```

**Características:**
- ⚠️ Se ejecuta en TU shell actual
- ⚠️ Las variables creadas persisten
- ⚠️ Los `cd` afectan tu directorio

**Cuándo usarlo:** Para cargar configuraciones o variables.

---

## Diferencia Práctica: source vs bash

Crea este script:

```bash
echo '#!/bin/bash
cd /tmp
MI_VAR="hola"
echo "Estoy en: $(pwd)"' > test.sh
```

**Con bash:**
```bash
bash test.sh
pwd           # Sigues en tu directorio original
echo $MI_VAR  # Vacío - la variable no existe aquí
```

**Con source:**
```bash
source test.sh
pwd           # ¡Estás en /tmp!
echo $MI_VAR  # "hola" - la variable existe
```

---

## ¿Cuál Usar?

| Método | Caso de Uso |
|--------|-------------|
| `bash script.sh` | Pruebas, scripts descargados |
| `./script.sh` | Scripts propios, uso frecuente |
| `source script.sh` | Cargar variables, `.bashrc` |

---

## 📋 Resumen

```bash
bash script.sh      # Subshell nueva, no afecta tu terminal
./script.sh         # Subshell nueva, necesita +x
source script.sh    # TU shell, variables persisten
. script.sh         # Igual que source
```

---

## 📚 Practica

1. Crea un script que haga `cd /tmp` y defina `TEST=123`
2. Ejecútalo con `bash`, verifica que no cambió tu directorio
3. Ejecútalo con `source`, verifica que SÍ cambió
4. Comprueba que `$TEST` existe después de source
