# Clase 5.1: Tu Primer Script en Bash

## 🎯 Objetivo
Crear y ejecutar tu primer script de bash.

## ⏱️ Duración: 5 minutos

---

## ¿Qué es un Script?

Un script es un archivo de texto con una lista de comandos. En lugar de escribir los comandos uno por uno, los pones todos en un archivo y los ejecutas juntos.

---

## Crear tu Primer Script

### 1. Crear el archivo

```bash
vim mi_script.sh
```

### 2. Escribir el contenido

```bash
#!/bin/bash
# Mi primer script

echo "¡Hola! Este es mi primer script"
echo "Hoy es: $(date)"
echo "Estoy en: $(pwd)"
echo "Mi usuario es: $(whoami)"
```

### 3. Guardar y salir en vim
- `Esc` (modo normal) → `:wq` → `Enter`
- O `:x` → `Enter` (guarda solo si hubo cambios)

---

## La Primera Línea: Shebang

```bash
#!/bin/bash
```

Esta línea se llama **shebang** y le dice al sistema qué programa usar para ejecutar el script.

| Shebang | Usa |
|---------|-----|
| `#!/bin/bash` | Bash |
| `#!/bin/sh` | Shell básico |
| `#!/usr/bin/python3` | Python 3 |

---

## Ejecutar el Script

### Opción 1: Con el comando `bash`

```bash
bash mi_script.sh
```

No necesitas permisos especiales, bash lee el archivo directamente.

### Opción 2: Como ejecutable (requiere permisos)

```bash
# Primero dar permisos de ejecución
chmod +x mi_script.sh

# Luego ejecutar
./mi_script.sh
```

El `./` indica "ejecutar este archivo del directorio actual".

---

## ¿Cuál usar?

| Método | Cuándo usarlo |
|--------|---------------|
| `bash script.sh` | Scripts rápidos, pruebas |
| `./script.sh` | Scripts que usarás frecuentemente |

---

## 📋 Resumen

```bash
vim script.sh            # Crear archivo (guardar y salir: Esc :wq Enter)
#!/bin/bash              # Primera línea del script
bash script.sh           # Ejecutar con bash
chmod +x script.sh       # Dar permisos
./script.sh              # Ejecutar directamente
```
