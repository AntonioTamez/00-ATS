# Clase 9.2: YUM, DNF y Otros Gestores de Paquetes

## 🎯 Objetivo
Entender que cada familia de Linux tiene su propio gestor de paquetes y saber usar YUM/DNF para sistemas Amazon Linux, RHEL y CentOS.

## ⏱️ Duración: 15 minutos

---

## El Mundo de los Gestores de Paquetes

Linux no es un solo sistema operativo, sino una familia de **distribuciones**. Cada familia tiene su propio gestor de paquetes. Conocerlos te evitará confusiones cuando trabajes en distintos servidores.

| Gestor | Familia / Distribuciones | Comando |
|--------|--------------------------|---------|
| **APT** | Debian, Ubuntu, Mint, Kali, Raspberry Pi OS | `apt install` |
| **YUM** | Amazon Linux 2, RHEL 7, CentOS 7 | `yum install` |
| **DNF** | Amazon Linux 2023, RHEL 8+, CentOS 8+, Fedora | `dnf install` |
| **APK** | Alpine Linux (muy usado en Docker) | `apk add` |
| **Pacman** | Arch Linux, Manjaro | `pacman -S` |
| **Zypper** | openSUSE | `zypper install` |
| **Brew** | macOS (no es Linux, pero es común en equipos) | `brew install` |

> 💡 **Para DevOps**: Los más importantes son **APT**, **YUM/DNF** y **APK** (cuando trabajas con imágenes Docker basadas en Alpine).

---

## YUM y DNF: La Familia Red Hat

**YUM** (Yellowdog Updater Modified) es el gestor clásico de la familia **Red Hat**. **DNF** es su sucesor moderno. Los comandos son casi idénticos.

### ¿Qué distribución usa qué?

| Distribución | Gestor |
|---|---|
| **Amazon Linux 2** | `yum` |
| **Amazon Linux 2023** | `dnf` |
| **RHEL 7 / CentOS 7** | `yum` |
| **RHEL 8+ / CentOS Stream** | `dnf` |
| **Fedora** | `dnf` |

> 💡 **Amazon Linux** es la distribución de AWS optimizada para sus servicios. Es basada en Red Hat, por eso usa YUM/DNF en lugar de APT.

---

## 📝 Guión de la Clase

### Demo 1: Actualizar el sistema

```bash
# Con yum (Amazon Linux 2, CentOS 7)
sudo yum update -y

# Con dnf (Amazon Linux 2023, RHEL 8+)
sudo dnf update -y
```

**Diferencia con APT:** YUM/DNF combinan `update` y `upgrade` en un solo paso. No necesitas dos comandos.

---

### Demo 2: Buscar e instalar paquetes

```bash
# Buscar un paquete
yum search nginx
dnf search nginx

# Ver información de un paquete
yum info nginx
dnf info nginx

# Instalar
sudo yum install nginx -y
sudo dnf install nginx -y

# Instalar varios
sudo yum install htop vim curl -y
```

---

### Demo 3: Eliminar y limpiar

```bash
# Eliminar paquete
sudo yum remove nginx -y
sudo dnf remove nginx -y

# Limpiar caché
sudo yum clean all
sudo dnf clean all
```

---

### Demo 4: Ver paquetes instalados

```bash
yum list installed
dnf list installed

# Filtrar
yum list installed | grep nginx
```

## APK: El Gestor de Alpine Linux

**Alpine Linux** es una distribución extremadamente liviana (~5MB). Por eso es la base de muchísimas **imágenes Docker**.

Cuando construyas o entres a contenedores Docker basados en Alpine, usarás `apk`:

```bash
# Actualizar lista de paquetes
apk update

# Instalar un paquete
apk add curl

# Instalar varios
apk add curl wget vim bash

# Eliminar
apk del curl

# Buscar
apk search nginx
```

> ⚠️ No te sorprendas si dentro de un contenedor Docker no existe `apt` ni `yum`. Si la imagen es Alpine, usas `apk`.

---

## Comparativa General

| Acción | APT (Ubuntu) | YUM/DNF (Amazon/RHEL) | APK (Alpine) |
|--------|---|---|---|
| Actualizar catálogo | `apt update` | (automático) | `apk update` |
| Actualizar paquetes | `apt upgrade` | `yum update` | `apk upgrade` |
| Instalar | `apt install` | `yum install` | `apk add` |
| Eliminar | `apt remove` | `yum remove` | `apk del` |
| Buscar | `apt search` | `yum search` | `apk search` |
| Limpiar caché | `apt clean` | `yum clean all` | (automático) |

---

## 💻 Resumen de Comandos (YUM/DNF)

```bash
sudo yum update -y              # Actualizar sistema
sudo yum install paquete -y     # Instalar
sudo yum remove paquete -y      # Eliminar
yum search texto                # Buscar
yum list installed              # Ver instalados
sudo yum clean all              # Limpiar caché

# Los mismos con dnf:
sudo dnf update -y
sudo dnf install paquete -y
sudo dnf remove paquete -y
```

---

## 📚 Practica (en Amazon Linux o contenedor)

1. Actualiza el sistema con `yum update`.
2. Busca el paquete `tree` con `yum search`.
3. Instálalo y verifica con `yum list installed | grep tree`.
4. (Extra) Lanza un contenedor Alpine y practica con `apk`:
   ```bash
   docker run -it alpine sh
   apk update
   apk add curl
   curl --version
   ```
