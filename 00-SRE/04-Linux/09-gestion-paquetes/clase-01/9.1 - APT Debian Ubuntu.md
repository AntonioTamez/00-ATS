# Clase 9.1: Gestión de Paquetes con APT

## 🎯 Objetivo
Entender qué es un gestor de paquetes, para qué sirve APT, y dominar sus comandos esenciales para instalar, actualizar y eliminar software en sistemas Debian/Ubuntu.

## ⏱️ Duración: 20-25 minutos

## ⚠️ Requisito: Sistema Debian/Ubuntu (o WSL con Ubuntu)

---

## ¿Qué es un Gestor de Paquetes?

Un **gestor de paquetes** es una herramienta que automatiza la instalación, actualización y eliminación de software en tu sistema. Sin él, tendrías que:
- Descargar archivos manualmente.
- Instalar dependencias una por una.
- Buscar actualizaciones en sitios web.

Con un gestor de paquetes, todo eso se hace con **un solo comando**. Es como la "App Store" de Linux, pero desde la terminal.

---

## APT: Para Debian, Ubuntu y derivadas

**APT** (Advanced Package Tool) es el gestor de paquetes de la familia **Debian/Ubuntu**. Lo encontrarás en:

| Distribución | Usa APT |
|---|---|
| Ubuntu (todas las versiones) | ✅ |
| Debian | ✅ |
| Linux Mint | ✅ |
| Pop!_OS | ✅ |
| Kali Linux | ✅ |
| Raspberry Pi OS | ✅ |

> 💡 **En DevOps**: La mayoría de los servidores en la nube (AWS, GCP, Azure) usan Ubuntu por defecto, por lo que APT es el gestor que más usarás.

---

## `apt` vs `apt-get` — ¿Cuál usar?

Puede que veas ambos en tutoriales. La diferencia:

| | `apt` | `apt-get` |
|---|---|---|
| ¿Cuándo apareció? | 2014 (Ubuntu 14.04) | 1998 (el original) |
| ¿Para uso interactivo? | ✅ Sí, tiene barra de progreso y colores | ⚠️ Pensado para scripts |
| ¿Para scripts? | ⚠️ Puede cambiar entre versiones | ✅ Estable, no cambia |

**Regla simple:**
- Si estás **en la terminal**, usa `apt`.
- Si estás **dentro de un script**, usa `apt-get` (para mayor compatibilidad).

En este curso usaremos `apt`.

## 📝 Guión de la Clase

### Demo 1: Actualizar sistema (3 min)

```bash
# Paso 1: Actualizar la lista de paquetes disponibles
# (Descarga el catálogo del repositorio, no instala nada)
sudo apt update

# Ver qué paquetes tienen actualizaciones pendientes
apt list --upgradable

# Paso 2: Instalar las actualizaciones
sudo apt upgrade -y

# Actualización completa (puede instalar/remover paquetes si es necesario)
sudo apt full-upgrade -y
```

**Explicar**: `update` descarga la lista, `upgrade` instala. Siempre `update` primero. Es como "actualizar el catálogo" antes de "ir a comprar".

---

### Demo 2: Buscar e instalar paquetes (5 min)

```bash
# Buscar un paquete por nombre o descripción
apt search nginx
apt search "web server"

# Ver información detallada de un paquete
apt show nginx

# Instalar un paquete
sudo apt install nginx -y

# Instalar varios a la vez
sudo apt install htop curl wget vim -y

# Verificar que quedó instalado
which nginx
nginx -v
```

---

### Demo 3: Eliminar paquetes (3 min)

```bash
# Eliminar el paquete pero dejar archivos de configuración
sudo apt remove nginx -y

# Eliminar el paquete Y sus archivos de configuración (recomendado)
sudo apt purge nginx -y

# Eliminar dependencias que ya no usa nadie
sudo apt autoremove -y

# Limpiar los instaladores descargados en caché
sudo apt clean
```

---

### Demo 4: Inspeccionar paquetes (3 min)

```bash
# Ver todos los paquetes instalados
apt list --installed

# Filtrar por nombre
apt list --installed | grep nginx

# Ver de qué paquete viene un archivo del sistema
dpkg -S /usr/bin/curl

# Ver todos los archivos que instaló un paquete
dpkg -L curl
```

---

### Demo 5: Reparar problemas (2 min)

```bash
# Si una instalación se interrumpió
sudo apt --fix-broken install

# Instalar un .deb descargado manualmente
sudo dpkg -i paquete.deb
sudo apt --fix-broken install  # Resolver sus dependencias
```

---

## 💻 Resumen de Comandos

```bash
sudo apt update                 # Actualizar catálogo
sudo apt upgrade -y             # Actualizar paquetes instalados
sudo apt install paquete -y     # Instalar
sudo apt remove paquete -y      # Eliminar (mantiene config)
sudo apt purge paquete -y       # Eliminar + configuración
sudo apt autoremove -y          # Limpiar dependencias huérfanas
sudo apt clean                  # Limpiar caché
apt search texto                # Buscar paquete
apt show paquete                # Información del paquete
apt list --installed            # Ver instalados
```

---

## 📋 Flujo de Mantenimiento Semanal

```bash
sudo apt update
sudo apt upgrade -y
sudo apt autoremove -y
sudo apt clean
```
