# Clase 6.1: Introducción a Cron

## 🎯 Objetivo
Entender cron y la sintaxis de crontab para programar tareas.

## ⏱️ Duración: 15-20 minutos

## ⚠️ Requisito: Servidor Linux

---

## 📝 Guión de la Clase

### Intro (2 min)
"Cron es el programador de tareas de Linux. Backups automáticos, limpieza de logs, scripts de monitoreo... todo se programa con cron."

### Demo 1: Sintaxis de crontab (5 min)

```bash
# Formato de una línea crontab:
# ┌───────────── minuto (0-59)
# │ ┌───────────── hora (0-23)
# │ │ ┌───────────── día del mes (1-31)
# │ │ │ ┌───────────── mes (1-12)
# │ │ │ │ ┌───────────── día de la semana (0-7, 0 y 7 = domingo)
# │ │ │ │ │
# * * * * * comando

# Ejemplos:
# 30 2 * * *     = 2:30 AM todos los días
# 0 * * * *      = Cada hora en punto
# */5 * * * *    = Cada 5 minutos
# 0 9 * * 1-5    = 9 AM de lunes a viernes
# 0 0 1 * *      = Medianoche del día 1 de cada mes
```

### Demo 2: Gestión de crontab (4 min)

```bash
# Ver crontab actual
crontab -l

# Editar crontab
crontab -e
# Se abre vim: agregar líneas, guardar y salir con Esc :wq Enter

# Eliminar crontab (¡CUIDADO!)
crontab -r

# Ver crontab de otro usuario (como root)
sudo crontab -u www-data -l

# Editar crontab de otro usuario
sudo crontab -u www-data -e
```

### Demo 3: Crear tareas programadas (5 min)

```bash
# Editar crontab
crontab -e

# Agregar estas líneas:
```

```cron
# Verificar espacio en disco cada hora
0 * * * * df -h > ./disk-usage.log

# Backup diario a las 3 AM
0 3 * * * /home/usuario/scripts/backup.sh

# Limpiar /tmp cada domingo a las 4 AM
0 4 * * 0 find /tmp -type f -mtime +7 -delete

# Script cada 5 minutos
*/5 * * * * /home/usuario/scripts/health-check.sh

# Solo días laborables a las 9 AM
0 9 * * 1-5 /home/usuario/scripts/daily-report.sh
```

### Demo 4: Operadores especiales (2 min)

```bash
# * = cualquier valor
# , = lista de valores (1,3,5)
# - = rango (1-5)
# / = paso (*/5 = cada 5)

# Ejemplos:
# 0,30 * * * *   = A las :00 y :30 de cada hora
# 0 9-17 * * *   = Cada hora de 9 AM a 5 PM
# */15 * * * *   = Cada 15 minutos
```

### Cierre (2 min)
"Memoriza la estructura: minuto, hora, día, mes, día-semana. En la siguiente clase veremos mejores prácticas y debugging."

```bash
crontab -l                  # Ver crontab

```

---

## 📋 Ejemplos de Horarios

| Expresión | Significado |
|-----------|-------------|
| `* * * * *` | Cada minuto |
| `0 * * * *` | Cada hora |
| `0 0 * * *` | Cada día a medianoche |
| `0 0 * * 0` | Cada domingo |
| `0 0 1 * *` | Primer día del mes |
| `*/5 * * * *` | Cada 5 minutos |
| `0 9-17 * * 1-5` | Cada hora de 9-17, L-V |
