# Clase 3.2: Alias - Atajos para Comandos

## 🎯 Objetivo
Crear atajos personalizados para comandos que usas frecuentemente.

## ⏱️ Duración: 5 minutos

---

## ¿Qué es un Alias?

Un alias es un atajo que creas para no escribir comandos largos. En lugar de escribir un comando completo, escribes una palabra corta.

---

## Crear un Alias (Temporal)

```bash
# Sintaxis
alias nombre='comando'

# Ejemplos
alias ll='ls -la'
alias cls='clear'
alias home='cd ~'

# Probar
ll
cls
home
```

⚠️ **Importante**: Estos alias solo duran mientras la terminal esté abierta. Al cerrarla, desaparecen.

---

## Ver Alias Existentes

```bash
# Ver todos los alias definidos
alias

# Ver un alias específico
alias ll
```

---

## Eliminar un Alias

```bash
# Eliminar alias
unalias ll

# Verificar
alias ll  # Ya no existe
```

---

## Hacer Alias Permanentes

Para que tus alias sobrevivan al cerrar la terminal, agrégalos a `~/.bashrc`:

```bash
# Abrir el archivo
vim ~/.bashrc

# Agregar al final del archivo:
alias ll='ls -la'
alias cls='clear'
alias update='sudo apt update && sudo apt upgrade -y'

# Guardar y salir en vim: Esc luego :wq y Enter

# Cargar los cambios
source ~/.bashrc
```

---

## Alias Útiles para DevOps

```bash
# Navegación
alias ..='cd ..'
alias ...='cd ../..'
alias home='cd ~'

# Listado
alias ll='ls -la'
alias la='ls -A'
alias l='ls -CF'

# Confirmación antes de borrar/sobrescribir
alias rm='rm -i'
alias cp='cp -i'
alias mv='mv -i'

# Sistema
alias cls='clear'
alias h='history'
alias update='sudo apt update && sudo apt upgrade -y'

# Red
alias myip='curl -s ifconfig.me'
alias ports='netstat -tulpn'

# Docker (si lo usas)
alias d='docker'
alias dc='docker-compose'
alias dps='docker ps'
```

---

## 📋 Resumen

```bash
alias nombre='comando'     # Crear alias
alias                      # Ver todos los alias
unalias nombre             # Eliminar alias
source ~/.bashrc           # Cargar cambios
```

---

## 📚 Practica

1. Crea un alias `cls` para `clear`
2. Crea un alias `ll` para `ls -la`
3. Agrega ambos a tu `~/.bashrc`
4. Cierra y abre la terminal para verificar que funcionan
