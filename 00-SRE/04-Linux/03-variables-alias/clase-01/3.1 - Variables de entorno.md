# Clase 3.1: Variables de Entorno

## 🎯 Objetivo
Entender y gestionar variables de entorno en Linux.

## ⏱️ Duración: 15-20 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"Las variables de entorno configuran el comportamiento de programas y scripts. En DevOps las usamos para credenciales, configuración de aplicaciones, y más."

### Demo 1: Ver variables (3 min)

```bash
# Ver todas las variables
env
printenv

# Ver variable específica
echo $PATH
echo $HOME
echo $USER
printenv HOME

# Variables importantes
echo $PATH      # Rutas de ejecutables
echo $HOME      # Directorio home
echo $USER      # Usuario actual
echo $SHELL     # Shell actual
echo $PWD       # Directorio actual
```

### Demo 2: Crear variables (4 min)

```bash
# Variable local (solo en esta shell)
MI_VAR="hola"
echo $MI_VAR

# Variable de entorno (disponible para procesos hijos)
export MI_VAR="hola"

# Verificar
env | grep MI_VAR

# En una línea
export DATABASE_URL="postgres://localhost:5432/mydb"

# Sin export, el subproceso no la ve
VAR_LOCAL="test"
bash -c 'echo $VAR_LOCAL'    # Vacío

export VAR_EXPORT="test"
bash -c 'echo $VAR_EXPORT'   # test
```

### Demo 3: Persistencia de variables (4 min)

```bash
# Variables en sesión actual se pierden al cerrar
# Para persistir, agregar a archivos de perfil:

# Para tu usuario (bash)
echo 'export MI_VAR="valor"' >> ~/.bashrc
source ~/.bashrc

# Para todos los usuarios
sudo echo 'export GLOBAL_VAR="valor"' >> /etc/environment

# Archivos de perfil:
# ~/.bashrc        - Cada shell interactiva (recomendado)
# ~/.bash_profile  - Solo login shells
# ~/.profile       - Login shells (sh, dash)
# /etc/environment - Sistema completo
```

### Demo 4: Variables en DevOps (4 min)

```bash
# AWS
export AWS_ACCESS_KEY_ID="AKIAXXXXXXXX"
export AWS_SECRET_ACCESS_KEY="secreto"
export AWS_DEFAULT_REGION="us-east-1"

# Docker
export DOCKER_HOST="tcp://localhost:2375"

# Kubernetes
export KUBECONFIG="$HOME/.kube/config"

# Aplicaciones
export NODE_ENV="production"
export DEBUG="false"
export LOG_LEVEL="info"
```

### Demo 5: Archivos .env (3 min)

```bash
# Crear archivo .env
cat << 'EOF' > .env
DATABASE_URL=postgres://localhost:5432/db
API_KEY=secret123
DEBUG=true
EOF

# Cargar variables de .env
set -a
source .env
set +a

# Verificar
echo $DATABASE_URL

# Otra forma
export $(cat .env | xargs)

# IMPORTANTE: Nunca commitear .env con secretos
echo ".env" >> .gitignore
```

### Cierre (2 min)
"export para variables de entorno, ~/.bashrc para persistencia, .env para configuración de aplicaciones."

---

## 💻 Comandos de la Clase

```bash
env                         # Ver todas las variables
echo $VARIABLE              # Ver variable específica
export VAR="valor"          # Crear variable de entorno
unset VAR                   # Eliminar variable
source ~/.bashrc            # Recargar perfil

# Cargar .env
set -a; source .env; set +a
export $(cat .env | xargs)
```
