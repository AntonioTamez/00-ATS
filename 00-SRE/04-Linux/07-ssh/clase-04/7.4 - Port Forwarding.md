# Clase 7.4: Port Forwarding (Túneles SSH)

## 🎯 Objetivo
Acceder a servicios remotos de forma segura a través de SSH.

## ⏱️ Duración: 5 minutos

---

## ¿Qué es Port Forwarding?

Imagina que tienes una base de datos en un servidor remoto que solo acepta conexiones locales. Con port forwarding, puedes acceder a ella desde tu PC como si fuera local.

---

## Túnel Local (-L)

**Caso:** Acceder a MySQL remoto (puerto 3306) desde tu PC.

```bash
ssh -L 3307:localhost:3306 usuario@servidor
```

**Explicación:**
- `-L` = Local forward
- `3307` = Puerto en TU PC
- `localhost:3306` = Destino en el servidor
- Ahora `localhost:3307` en tu PC → MySQL del servidor

**Usar:**
```bash
mysql -h 127.0.0.1 -P 3307 -u usuario -p
```

---

## Diagrama

```
Tu PC                    Servidor Remoto
┌─────────────┐          ┌─────────────┐
│ localhost   │  SSH     │  MySQL      │
│ :3307  ────────────────→ :3306      │
└─────────────┘          └─────────────┘
```

---

## Ejemplos Prácticos

### Acceder a aplicación web interna
```bash
# La app corre en el servidor en puerto 8080
ssh -L 8080:localhost:8080 usuario@servidor

# Ahora abre en tu navegador: http://localhost:8080
```

### Acceder a Redis remoto
```bash
ssh -L 6379:localhost:6379 usuario@servidor

# Conectar con redis-cli local
redis-cli
```

### Acceder a servicio en otra máquina de la red
```bash
# El servidor puede ver 10.0.0.5:5432, tú no
ssh -L 5432:10.0.0.5:5432 usuario@servidor

# Ahora localhost:5432 → 10.0.0.5:5432
```

---

## Mantener el Túnel en Background

```bash
# -f = background, -N = no ejecutar comandos
ssh -f -N -L 3307:localhost:3306 usuario@servidor
```

Para cerrar:
```bash
# Buscar el proceso
ps aux | grep ssh

# Matarlo
kill <PID>
```

---

## 📋 Resumen

```bash
# Túnel local
ssh -L puerto_local:destino:puerto_destino usuario@servidor

# En background
ssh -f -N -L 8080:localhost:8080 usuario@servidor
```
