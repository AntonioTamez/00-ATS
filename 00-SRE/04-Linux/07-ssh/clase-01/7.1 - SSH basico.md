# Clase 7.1: SSH - Conexiones Remotas Seguras

## 🎯 Objetivo
Dominar SSH para conectarse a servidores remotos de forma segura.

## ⏱️ Duración: 20-25 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"SSH es la forma estándar de conectarse a servidores. En DevOps, lo usarás miles de veces para administrar servidores, desplegar aplicaciones y transferir archivos."

### Demo 1: Conexión básica (4 min)

```bash
# Validar si el puerto 22 de SSH está abierto antes de conectarse
telnet servidor 22
# Escape character is '^]'. (Significa que conectó con éxito. Presiona Ctrl+] y luego escribe quit para salir)

# Conexión básica
ssh usuario@servidor
ssh usuario@192.168.1.100

# Con puerto personalizado
ssh -p 2222 usuario@servidor

# Ejecutar comando sin login interactivo
ssh usuario@servidor "uptime"
ssh usuario@servidor "df -h"
ssh usuario@servidor "docker ps"
```

### Demo 2: Autenticación con llaves SSH (6 min)

```bash
# Generar par de llaves (en tu máquina local)
ssh-keygen -t ed25519 -C "jean@example.com"
# Enter file: ~/.ssh/id_ed25519 (default)
# Passphrase: (opcional pero recomendado)

# Ver las llaves generadas
ls -la ~/.ssh/
# id_ed25519      <- Llave PRIVADA (NUNCA compartir)
# id_ed25519.pub  <- Llave pública (esta se copia al servidor)

# Copiar llave pública al servidor
ssh-copy-id usuario@servidor

# Ahora puedes conectar sin password, indicando la llave privada con -i
ssh -i ~/.ssh/id_ed25519 usuario@servidor
# Nota: ssh usará la llave por defecto de forma automática, por lo que a veces puedes omitir -i
ssh usuario@servidor
```

**Explicar**: "La llave privada es como tu DNI, nunca la compartes. La pública es como tu número de teléfono, la das a quien quieras que te contacte."

### Cierre (2 min)
"SSH con llaves es mucho más seguro que usar passwords, y es el estándar de la industria. Siempre debes validar la conexión básica primero."

---

## 💻 Comandos de la Clase

```bash
telnet servidor 22                # Validar apertura de puerto SSH
ssh usuario@servidor              # Conexión básica
ssh -p 2222 usuario@servidor      # Puerto personalizado
ssh usuario@servidor "comando"    # Ejecutar comando remoto

ssh-keygen -t ed25519             # Generar llaves
ssh-copy-id usuario@servidor      # Copiar llave pública
ssh -i /ruta/llave user@server    # Conectar usando llave específica privada
```

---

## 📚 Tarea para el Estudiante
1. Validar con `telnet` que el puerto SSH del servidor esté abierto.
2. Conectarse de forma básica usando nombre de usuario y contraseña.
3. Generar un par de llaves SSH (usando ed25519).
4. Copiar la llave pública a tu servidor usando `ssh-copy-id`.
5. Conectar usando la llave privada y comprobando que funciona con la bandera `-i`.
