# Clase 7.2: SSH con Llaves (Keys)

## 🎯 Objetivo
Conectarte a servidores sin escribir contraseña usando llaves SSH.

## ⏱️ Duración: 5-7 minutos

---

## ¿Por Qué Usar Llaves?

| Con contraseña | Con llaves |
|----------------|------------|
| Escribir pass cada vez | Sin contraseña |
| Menos seguro | Más seguro |
| Vulnerable a fuerza bruta | Casi imposible de hackear |

---

## Generar tu Par de Llaves

En tu máquina local (no en el servidor):

```bash
ssh-keygen -t ed25519 -C "tu@email.com"
```

Te preguntará:
1. **Ubicación**: Presiona Enter para usar la default (`~/.ssh/id_ed25519`)
2. **Passphrase**: Opcional, agrega seguridad extra

---

## ¿Qué se creó?

```bash
ls -la ~/.ssh/
```

| Archivo | Qué es | ¿Compartir? |
|---------|--------|-------------|
| `id_ed25519` | Llave PRIVADA | ❌ NUNCA |
| `id_ed25519.pub` | Llave pública | ✅ Sí |

La llave privada es como tu DNI. La pública es como tu número de teléfono.

---

## Copiar la Llave al Servidor

### Método fácil:
```bash
ssh-copy-id usuario@servidor
```

### Método manual:
```bash
# Ver tu llave pública
cat ~/.ssh/id_ed25519.pub

# Copiar el contenido y en el servidor:
echo "TU_LLAVE_PUBLICA" >> ~/.ssh/authorized_keys
```

---

## Conectar Sin Contraseña

Ahora simplemente:

```bash
ssh -i ~/.ssh/id_ed25519 usuario@servidor
```

¡Sin contraseña! 🎉

---

## Usar Llave Específica

Si tienes varias llaves:

```bash
ssh -i ~/.ssh/mi_otra_llave usuario@servidor
```

---


## 📋 Resumen

```bash
ssh-keygen -t ed25519                  # Generar llaves
ssh-copy-id usuario@servidor           # Copiar al servidor
ssh -i ~/.ssh/llave usuario@servidor   # Conectar usando llave específica (sin pass)
```

---

## 📚 Practica

1. Genera un par de llaves ed25519
2. Copia tu llave pública a tu servidor Linux
3. Conéctate sin contraseña asegurándote de usar el flag `-i`
