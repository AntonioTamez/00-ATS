# Clase 7.3: Archivo de Configuración SSH

## 🎯 Objetivo
Configurar el archivo de configuración SSH para conectarte más fácil a tus servidores sin recordar IPs, usuarios ni rutas de llaves.

## ⏱️ Duración: 5-7 minutos

---

## Archivo de Configuración SSH

Para no escribir todo cada vez, crea `~/.ssh/config`:

```bash
vim ~/.ssh/config
# Guardar y salir: Esc luego :wq y Enter
```

```
Host mi-servidor
    HostName 192.168.1.100
    User ubuntu
    IdentityFile ~/.ssh/id_ed25519

Host aws-prod
    HostName 54.23.45.67
    User ec2-user
    IdentityFile ~/.ssh/aws-key.pem
```

Ahora conectas con:
```bash
ssh mi-servidor
ssh aws-prod
```

---

## 📋 Resumen

El archivo `~/.ssh/config` sirve para crear alias fáciles de recordar. Puedes definir qué usuario, IP (HostName) y llave privada (IdentityFile) usar para cada servidor.

---

## 📚 Practica

1. Crea o abre el archivo `~/.ssh/config`
2. Crea un alias para tu servidor o VM
3. Conéctate a tu servidor usando solamente `ssh tu-alias`
