# Clase 7.5: Copiar Archivos (scp y rsync)

## 🎯 Objetivo
Transferir archivos entre tu PC y servidores remotos.

## ⏱️ Duración: 5 minutos

---

## SCP - Secure Copy

### Subir archivo al servidor

```bash
scp archivo.txt usuario@servidor:/ruta/destino/
```

### Descargar archivo del servidor

```bash
scp usuario@servidor:/ruta/archivo.txt ./local/
```

### Subir directorio completo

```bash
scp -r mi_carpeta/ usuario@servidor:/ruta/destino/
```

---

## Ejemplos SCP

```bash
# Subir un script
scp deploy.sh ubuntu@54.23.45.67:/home/ubuntu/

# Descargar logs
scp ubuntu@54.23.45.67:/var/log/app.log ./

# Subir carpeta de proyecto
scp -r proyecto/ ubuntu@54.23.45.67:/var/www/
```

---

## RSYNC - Sincronización Inteligente

rsync es más eficiente que scp porque solo copia lo que cambió.

### Subir y sincronizar

```bash
rsync -avz ./local/ usuario@servidor:/remoto/
```

**Flags:**
- `-a` = archive (mantiene permisos, fechas, etc.)
- `-v` = verbose (muestra progreso)
- `-z` = comprime durante transferencia

### Con barra de progreso

```bash
rsync -avz --progress ./local/ usuario@servidor:/remoto/
```

---

## Diferencia entre SCP y RSYNC

| SCP | RSYNC |
|-----|-------|
| Copia todo siempre | Solo copia cambios |
| Más simple | Más eficiente |
| Para archivos pequeños | Para proyectos grandes |

---

## Sincronizar y Eliminar Extras

```bash
rsync -avz --delete ./local/ usuario@servidor:/remoto/
```

⚠️ `--delete` elimina archivos en destino que no existen en origen.

---

## Excluir Archivos

```bash
rsync -avz --exclude='node_modules' --exclude='.git' ./proyecto/ usuario@servidor:/app/
```

---

## 📋 Resumen

```bash
# SCP
scp archivo usuario@server:/ruta/         # Subir
scp usuario@server:/ruta/archivo ./       # Descargar
scp -r carpeta/ usuario@server:/ruta/     # Directorio

# RSYNC
rsync -avz ./origen/ usuario@server:/destino/
rsync -avz --progress ./origen/ usuario@server:/destino/
rsync -avz --delete ./origen/ usuario@server:/destino/
```

---

## 📚 Practica

1. Crea un archivo `test.txt` y súbelo a tu VM con scp
2. Descarga `/etc/hostname` de tu VM
3. Crea una carpeta con archivos y sincronízala con rsync
4. Modifica un archivo y usa rsync de nuevo (nota que es más rápido)
