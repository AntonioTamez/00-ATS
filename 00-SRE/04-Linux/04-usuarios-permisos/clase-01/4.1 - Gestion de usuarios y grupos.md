# Clase 4.1: Gestión de Usuarios y Grupos

## 🎯 Objetivo
Aprender a crear y gestionar usuarios y grupos en Linux.

## ⏱️ Duración: 15-20 minutos

## ⚠️ Requisito: Servidor Linux con permisos sudo

---

## 📝 Guión de la Clase

### Intro (2 min)
"La seguridad en Linux empieza con una buena gestión de usuarios. Cada servicio, cada aplicación, debe tener su propio usuario con los mínimos privilegios necesarios."

### Demo 1: Ver información de usuarios (3 min)

```bash
# Usuario actual
whoami

# Info completa del usuario
id
id usuario

# Ver grupos del usuario
groups
groups usuario

# Listar todos los usuarios
cat /etc/passwd | awk -F: '{print $1}'
# Listar todos los grupos
cat /etc/group | awk -F: '{print $1}'
```

### Demo 2: Crear usuarios (5 min)

```bash
# Crear usuario básico
sudo useradd desarrollador

# Crear usuario con home y shell
sudo useradd -m -s /bin/bash devops
# -m = crear directorio home
# -s = shell por defecto

# Establecer contraseña
sudo passwd devops

# Crear usuario con grupo específico
sudo useradd -m -s /bin/bash -g developers frontend

# Crear usuario del sistema (para servicios)
sudo useradd -r -s /bin/false appservice
# -r = usuario de sistema (UID bajo)
# /bin/false = no puede hacer login
```

### Demo 3: Modificar usuarios (3 min)

```bash
# Cambiar shell
sudo usermod -s /bin/zsh devops

# Agregar a grupo suplementario
sudo usermod -aG docker devops
sudo usermod -aG sudo devops
# -a = append (agregar sin quitar otros grupos)
# -G = grupos suplementarios

# Cambiar nombre de usuario
sudo usermod -l nuevo_nombre viejo_nombre
```

### Demo 4: Grupos (3 min)

```bash
# Crear grupo
sudo groupadd developers
sudo groupadd -g 1500 customgroup  # Con GID específico

# Agregar usuario a grupo
sudo usermod -aG developers devops

# Verificar
groups devops

# Eliminar grupo
sudo groupdel customgroup
```

### Demo 5: Eliminar usuarios (2 min)

```bash
# Eliminar usuario (mantiene home)
sudo userdel desarrollador

# Eliminar usuario y su home
sudo userdel -r frontend

# Bloquear usuario (sin eliminar)
sudo usermod -L devops

# Desbloquear
sudo usermod -U devops
```

### Cierre (2 min)
"Nunca ejecutes servicios como root. Crea usuarios específicos con los mínimos privilegios necesarios."

---

## 💻 Comandos de la Clase

```bash
whoami                              # Usuario actual
id                                  # Info de usuario
groups usuario                      # Grupos del usuario

sudo useradd -m -s /bin/bash user   # Crear usuario
sudo passwd user                    # Establecer password
sudo usermod -aG grupo user         # Agregar a grupo
sudo userdel -r user                # Eliminar usuario

sudo groupadd grupo                 # Crear grupo
sudo groupdel grupo                 # Eliminar grupo
```
