# Clase 4.2: Permisos de Archivos

## 🎯 Objetivo
Dominar chmod, chown y entender el sistema de permisos de Linux.

## ⏱️ Duración: 20-25 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"Los permisos determinan quién puede leer, escribir o ejecutar un archivo. Entenderlos es fundamental para la seguridad."

### Demo 1: Entender la salida de ls -l (5 min)

```bash
ls -la
# Output:
# -rw-r--r-- 1 jean developers 1234 Jan 15 10:00 archivo.txt
# drwxr-xr-x 2 jean developers 4096 Jan 15 10:00 directorio/

# Desglose: -rw-r--r--
# -         = Tipo (- archivo, d directorio, l link)
# rw-       = Permisos del PROPIETARIO (user)
# r--       = Permisos del GRUPO (group)
# r--       = Permisos de OTROS (others)

# r = read (lectura)      = 4
# w = write (escritura)   = 2
# x = execute (ejecución) = 1
# - = sin permiso         = 0
```

### Demo 2: chmod - Modo simbólico (4 min)

```bash
# Crear archivo de prueba
touch ./test.txt
ls -l ./test.txt

# Agregar permiso de ejecución al propietario
chmod u+x ./test.txt

# Quitar escritura a grupo y otros
chmod go-w ./test.txt

# Dar lectura a todos
chmod a+r ./test.txt

# Sintaxis:
# u = user (propietario)
# g = group (grupo)
# o = others (otros)
# a = all (todos)
# + = agregar permiso
# - = quitar permiso
# = = establecer exactamente

chmod u=rwx,g=rx,o=r ./test.txt
```

### Demo 3: chmod - Modo octal (5 min)

```bash
# Octal es más rápido una vez lo aprendes
# r=4, w=2, x=1

# rwxr-xr-x = 755
chmod 755 ./test.txt

# rw-r--r-- = 644
chmod 644 ./test.txt

# rwx------ = 700
chmod 700 ./test.txt

# Permisos comunes:
# 755 = Scripts ejecutables, directorios
# 644 = Archivos normales
# 600 = Archivos privados (llaves SSH)
# 700 = Directorios privados (.ssh)
# 777 = TODO el mundo puede TODO (¡EVITAR!)

# Recursivo
chmod -R 755 ./directorio/
```

### Demo 4: chown - Cambiar propietario (3 min)

```bash
# Cambiar propietario
sudo chown usuario ./test.txt

# Cambiar propietario y grupo
sudo chown usuario:grupo ./test.txt

# Solo cambiar grupo
sudo chown :grupo ./test.txt
# o
sudo chgrp grupo ./test.txt

# Recursivo
sudo chown -R usuario:grupo /opt/mi-app/
```

### Demo 5: Permisos esenciales en DevOps (3 min)

```bash
# Llaves SSH - MUY importante
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519      # Llave privada
chmod 644 ~/.ssh/id_ed25519.pub  # Llave pública
chmod 644 ~/.ssh/known_hosts

# Scripts ejecutables
chmod 755 deploy.sh

# Archivos de configuración sensibles
chmod 600 .env
chmod 600 config/secrets.yml

# Directorios de aplicación web
chmod 755 /var/www/html
chown -R www-data:www-data /var/www/html
```

### Cierre (2 min)
"755 para ejecutables, 644 para archivos, 600 para secretos. Memoriza estos números."

## 💻 Comandos de la Clase

```bash
# Modo simbólico
chmod u+x archivo           # Agregar ejecución a usuario
chmod g-w archivo           # Quitar escritura a grupo
chmod o=r archivo           # Otros solo lectura
chmod a+r archivo           # Lectura para todos

# Modo octal
chmod 755 archivo           # rwxr-xr-x
chmod 644 archivo           # rw-r--r--
chmod 600 archivo           # rw-------
chmod -R 755 directorio/    # Recursivo

# Propietario
sudo chown user archivo
sudo chown user:group archivo
sudo chown -R user:group dir/
```

## 📋 Tabla de Permisos Octal

| Octal | Binario | Permisos | Uso común |
|-------|---------|----------|-----------|
| 7 | 111 | rwx | Directorios, scripts |
| 6 | 110 | rw- | Archivos editables |
| 5 | 101 | r-x | Directorios (sin escribir) |
| 4 | 100 | r-- | Solo lectura |
| 0 | 000 | --- | Sin acceso |

**Combinaciones comunes:** 755, 644, 700, 600, 775
