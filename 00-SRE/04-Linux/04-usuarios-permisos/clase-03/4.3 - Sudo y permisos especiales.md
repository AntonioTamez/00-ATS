# Clase 4.3: Sudo

## 🎯 Objetivo
Entender qué es sudo y cómo usarlo para ejecutar comandos como administrador.

## ⏱️ Duración: 8-10 minutos

---

## 📝 Guión de la Clase

### Intro (2 min)
"sudo te permite ejecutar comandos como root sin ser root. Es la forma segura de administrar sistemas."

### Demo: Uso de sudo (5 min)

```bash
# Ejecutar comando como root
sudo apt update

# Ejecutar como otro usuario
sudo -u www-data whoami

# Shell interactivo como root
sudo -i
# o
sudo su -

# Ejecutar último comando con sudo
sudo !!

# Ver qué puedo hacer con sudo
sudo -l
```

### Cierre (2 min)
"Usa sudo cuando necesites permisos de administrador. No trabajes como root directamente."

---

## 💻 Comandos de la Clase

```bash
sudo comando              # Ejecutar como root
sudo -u user comando      # Ejecutar como usuario
sudo -i                   # Shell como root (también: sudo su -)
sudo !!                   # Repetir último comando con sudo
sudo -l                   # Ver qué permisos sudo tienes
```
