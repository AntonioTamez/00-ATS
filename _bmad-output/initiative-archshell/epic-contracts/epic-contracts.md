# Contracts as data, frozen and checked for breaking changes

## Description

Contracts are proposed as data in a closed type system, generated by the pack, confirmed in plain language when public, frozen before the RED test, and checked for breaking changes by diffing contract data.

## Outcome

The agent cannot drift a public contract; the signal is that an unconfirmed breaking change fails the gates and `verify`.

## Requirements

- CAP-8: FR-47–FR-51 (AD-13).

## Done when

1. The same contract data produces byte-identical code on the three OSes.
2. The agent cannot change a frozen contract; the attempt is blocked in session.
3. An unconfirmed breaking change fails the full gates and `verify`.
4. A public contract is confirmed with a plain-language summary in the developer's language.
5. Merged to `main` with CI green on Windows, Linux, and macOS, and published as a pre-release (engine to TestPyPI, analyzer to GitHub Packages NuGet).

## Boundaries

Capability boundary: contracts only; adds its checks to `verify`. Spec non-goals apply.
