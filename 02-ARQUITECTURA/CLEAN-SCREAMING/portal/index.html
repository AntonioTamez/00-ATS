Clean + Screaming para novatos

Dos ideas de Uncle Bob que se completan: Screaming hace que las carpetas hablen del negocio; Clean hace que las dependencias apunten hacia adentro. Juntas, y con el compilador vigilando.

1. Cada una cubre el hueco de la otra

Screaming negocio

"Your architectures should tell readers about the system, not about the frameworks you used."

Le falta: no dice nada sobre hacia dónde apuntan las dependencias.

Clean dependencias

"Source code dependencies can only point inwards."

Le falta: no dice cómo se llaman las carpetas; el resultado típico grita Domain/Application/Infrastructure.

Juntas

Primer nivel = capacidades del negocio. Dentro de cada una, los círculos de Clean como proyectos: el compilador impide romper la regla.
