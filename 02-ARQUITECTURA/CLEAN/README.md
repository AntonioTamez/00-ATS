# Clean Architecture – learning kit

| Path | What it is |
|---|---|
| `docs/GUIA-CLEAN-ARCHITECTURE.md` | Step-by-step guide (Spanish) to build a Clean Architecture project from scratch |
| `sample/` | Reference .NET 10 solution (TodoApp) applying the guide; `dotnet test` runs 18 tests |
| `portal/index.html` | Interactive beginner portal (open it in a browser, no build needed) |

Run the sample: `cd sample && dotnet test` / `dotnet run --project src/TodoApp.Api`.
